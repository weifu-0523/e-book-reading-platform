## 应用图标生成

图标源文件 `app/assets/icon.png`（推荐 1024×1024 PNG）。运行：

```bash
cd app && dart run flutter_launcher_icons
```

会重新生成 Android 各分辨率 mipmap + Windows .ico。

修改源文件后请重新运行此命令并提交所有生成产物。
