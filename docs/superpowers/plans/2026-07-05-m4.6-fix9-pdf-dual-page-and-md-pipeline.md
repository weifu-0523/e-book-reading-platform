## Goal

按 spec 实现 PDF 单 PdfViewer 双页（方案 A）+ MD scroll 管线，根除 PDF 死锁导致的 exe 僵尸进程，修复 MD 段落溢出。TXT 与 EPUB 零改动。

## Architecture（来自 spec §4）

- **PDF**：单个 `PdfViewer.data()` 主区 + `PdfPage.render()` 副页位图预览。一份 PdfDocument，dispose 干净。
- **PDF dispose 安全网**：`_doc.dispose()` 加 3 秒 timeout，超时不阻塞 stream 关闭。
- **MD**：`reader_engine_provider` 里 MD 路由调 `setPaginationMode(scroll)`，复用既有 `_buildScroll`（SingleChildScrollView + HtmlWidget）。TXT 不调，保持 paged。

## Task 1: PDF 单 PdfViewer + 副页位图（核心）

**Files**: `reader_engine_pdf_view/lib/pdf_renderer.dart`

**Background**: 当前 `_buildDualPage` 用两个 `PdfViewer.data()`（sourceName `#L`/`#R`），导致同一份 PDF 被 pdfium 加载两次，dispose 死锁。改为单 PdfViewer 主区 + `PdfPage.render()` 副页位图。

### Steps

- [ ] 1.1 删除 `_leftController` / `_rightController` 两个字段及所有引用
- [ ] 1.2 新增副页状态字段：`Uint8List? _dualPreviewBytes` / `int? _dualPreviewPageIdx`
- [ ] 1.3 重写 `_buildDualPage`：
  - 左 Expanded：单个 `PdfViewer.data(bytes, controller: _mainController, initialPageNumber: leftIdx+1)`
  - 右 Expanded：`FutureBuilder<PdfImage?>` 调 `_renderDualPreview(doc, rightIdx)` 渲染副页位图，`CustomPaint` 绘制
  - 翻页（`setPage`）时 setState 触发副页重新 render
- [ ] 1.4 新增 `_renderDualPreview(PdfDocument doc, int pageIdx0)`：
  - 调 `doc.pages[pageIdx0].render(fullWidth: containerWidth * dpr, fullHeight: ...)` 
  - 加 `limitedImageCache` flag
  - 用 try-catch 包裹，失败返回 null（副页显示"加载失败"占位）
- [ ] 1.5 `setPage` 在 dual 模式分支：调 `_mainController.goToPage(leftIdx+1)` + setState 触发副页 render
- [ ] 1.6 `onViewerReady`：只保留主页 controller 赋值，删除左右分别 goToPage 的逻辑
- [ ] 1.7 保留所有 `pdfDiagLog` 日志，新增 `_renderDualPreview` 的成功/失败日志
- [ ] 1.8 验证：`dart analyze` 无错误

### Verification

- [ ] `flutter test --no-pub --concurrency=1 test/pdf_renderer_test.dart`
- [ ] `flutter test --no-pub --concurrency=1 test/pdf_renderer_dual_page_test.dart`（可能需更新断言）
