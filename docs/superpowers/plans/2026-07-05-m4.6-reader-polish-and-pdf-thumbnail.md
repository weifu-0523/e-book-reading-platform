## Task 3 — TXT 智能启发式分段（Bug #6）

**Files**：
- `app/lib/services/text_book_loader.dart`
- `app/test/services/text_book_loader_test.dart`

**Background**：重写 `parseText`，按 spec A5 启发式规则。核心：长行**每行独立 `<p>`**（杜绝超长单段），短行独立成段，空行作分隔。

### Steps
- [ ] 3.1 `text_book_loader.dart:60-75` 重写 `parseText`：
  ```dart
  static String parseText(String text) {
    if (text.trim().isEmpty) return '<p></p>';
    
    final lines = text.split('\n');
    final buf = StringBuffer();
    
    for (final rawLine in lines) {
      final line = rawLine.trim();
      if (line.isEmpty) {
        continue; // 空行作分隔符，不输出 <p>
      }
      if (_isShortLine(line)) {
        // 短行（标题/分隔）：独立成 <p>
        buf.write('<p>${_escapeHtml(line)}</p>');
      } else {
        // 长行：独立成 <p>（中文小说每行一段事实标准）
        buf.write('<p>${_escapeHtml(line)}</p>');
      }
    }
    
    final result = buf.toString();
    return result.isEmpty ? '<p></p>' : result;
  }
  
  /// 短行判定：长度 ≤ 2 字符，或全是标点符号。
  static bool _isShortLine(String line) {
    if (line.length <= 2) return true;
    // 全标点（中英文标点、空格已 trim 掉）
    final allPunct = RegExp(r'^[\p{P}\s]+$', unicode: true);
    return allPunct.hasMatch(line);
  }
  ```
  **关键简化**：长行和短行当前都独立成 `<p>`（视觉一致），但保留 `_isShortLine` 区分是为了未来扩展（比如短行不加段前距）。如果想更精确，可让长行连续行用 `<br>` 合并成一个 `<p>`——**但 spec A5 明确说"长行不合并，每行独立 `<p>`"**，避免重蹈 Bug #6 覆辙。

### Steps
- [ ] 5.1 新建 `pdf_thumbnail_grid.dart`：
  ```dart
  /// PDF 无目录时的页面缩略图导航 grid。
  /// 用 pdfrx PdfPage.render() 异步渲染，内存 LRU 缓存 32 张，
  /// GridView.builder 只构建可视区 + 前后各 5 个 cell。
  class PdfThumbnailGrid extends StatefulWidget {
    final PdfDocument document;
    final int currentPage; // 0-based
    final ValueChanged<int> onPageSelected; // 0-based page index
    
    const PdfThumbnailGrid({
      super.key,
      required this.document,
      required this.currentPage,
      required this.onPageSelected,
    });
    
    @override
    State<PdfThumbnailGrid> createState() => _PdfThumbnailGridState();
  }
  
  class _PdfThumbnailGridState extends State<PdfThumbnailGrid> {
    /// LRU 缓存：page index → ui.Image。容量 32，超出淘汰最旧。
    final _cache = <int, ui.Image>{};
    static const int _maxCache = 32;
    
    /// 正在渲染的 page index 集合（避免重复触发）。
    final _rendering = <int>{};
    
    @override
    void dispose() {
      for (final img in _cache.values) {
        img.dispose();
      }
      _cache.clear();
      super.dispose();
    }
    
    Future<void> _renderThumbnail(int pageIndex) async {
      if (_cache.containsKey(pageIndex) || _rendering.contains(pageIndex)) return;
      _rendering.add(pageIndex);
      try {
        final page = widget.document.pages[pageIndex];
        // 缩略图宽度 200，高度按 PDF 页比例
        final thumbWidth = 200.0;
        final scale = thumbWidth / page.width;
        final thumbHeight = (page.height * scale).round();
        final rendered = await page.render(
          width: thumbWidth,
          height: thumbHeight.toDouble(),
        );
        if (!mounted) return;
        setState(() {
          _cache[pageIndex] = rendered.image;
          // LRU 淘汰
          while (_cache.length > _maxCache) {
            final oldestKey = _cache.keys.first;
            _cache[oldestKey]?.dispose();
            _cache.remove(oldestKey);
          }
        });
      } catch (e) {
        // 渲染失败：留空 cell，不阻塞其他页
        debugPrint('PDF thumbnail render failed for page $pageIndex: $e');
      } finally {
        _rendering.remove(pageIndex);
      }
    }
    
    @override
    Widget build(BuildContext context) {
      return GridView.builder(
        padding: const EdgeInsets.all(8),
        gridDelegate: const SliverGridDelegateWithMaxCrossAxisExtent(
          maxCrossAxisExtent: 220,
          childAspectRatio: 0.7, // PDF 页通常竖长
          crossAxisSpacing: 8,
          mainAxisSpacing: 8,
        ),
        itemCount: widget.document.pages.length,
        itemBuilder: (context, index) {
          // 进入可视区附近时触发渲染（builder 本身只构建可见 cell）
          final thumb = _cache[index];
          final isCurrent = index == widget.currentPage;
          
          // 触发渲染（post-frame 避免在 build 中调 setState）
          WidgetsBinding.instance.addPostFrameCallback((_) {
            _renderThumbnail(index);
          });
          
          return GestureDetector(
            onTap: () => widget.onPageSelected(index),
            child: Container(
              decoration: BoxDecoration(
                border: Border.all(
                  color: isCurrent ? Theme.of(context).colorScheme.primary : Colors.grey.shade300,
                  width: isCurrent ? 3 : 1,
                ),
                borderRadius: BorderRadius.circular(4),
              ),
              child: thumb == null
                ? const Center(child: CircularProgressIndicator(strokeWidth: 2))
                : ClipRRect(
                    borderRadius: BorderRadius.circular(3),
                    child: RawImage(
                      image: thumb,
                      fit: BoxFit.contain,
                    ),
                  ),
            ),
          );
        },
      );
    }
  }
  ```
  **关键点**：
  - `_renderThumbnail` 是幂等的（_cache / _rendering 双重检查）
  - LRU 淘汰用 `keys.first`（Map 在 Dart 1.22+ 保持插入顺序），淘汰最旧的
  - 缩略图 `ui.Image.dispose()` 在 LRU 淘汰和 widget dispose 时调用，防内存泄漏
  - post-frame callback 触发渲染，避免在 build 中调 setState 报错
  - import 需要 `dart:ui` as ui、`package:flutter/material.dart`、`package:pdfrx/pdfrx.dart`
