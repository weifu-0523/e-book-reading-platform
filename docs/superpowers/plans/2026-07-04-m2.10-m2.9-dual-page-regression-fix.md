## Step 1 — Fix Bug A：paged 页内容包 SingleChildScrollView 吸收高度误差

**文件**: `reader_engine_epub_view/lib/epubx_renderer.dart` `_buildPaged` 的 `buildSinglePage`（~line 883-905）

**改动**：`buildSinglePage` 返回的 `Padding(EdgeInsets.all(margin), child: HtmlWidget(...))`
外面再包一层 `SingleChildScrollView(physics: NeverScrollableScrollPhysics(), child: ...)`。

```dart
Widget buildSinglePage(int breakIdx) {
  final pb = breaks[breakIdx];
  final start = pb.startOffset.clamp(0, plain.length);
  final end = pb.endOffset.clamp(start, plain.length);
  var pageHtml = HtmlSlicer.sliceByPlainRange(html, start, end, plainLength: plain.length);
  final localHl = pageHighlights[breakIdx];
  if (localHl != null) {
    pageHtml = HtmlHighlightInjector.inject(pageHtml, localHl);
  }
  // M2.10/Bug A: 页内容包 SingleChildScrollView(NeverScrollable) 吸收 HtmlWidget
  // 与 TextPainter 的高度误差。双页模式宽度 halve 放大误差，某页真实高度 > 固定
  // slot 高度会抛 RenderFlex overflow assertion（黄黑斑马线）。可滚动容器让误差
  // 自然吸收（不溢出即不滚），与 _buildScroll 模式一致。
  return SingleChildScrollView(
    physics: const NeverScrollableScrollPhysics(),
    child: Padding(
      padding: EdgeInsets.all(margin),
      child: HtmlWidget(
        pageHtml,
        textStyle: style.copyWith(color: fg),
      ),
    ),
  );
}
```

- [ ] 改 `buildSinglePage`
- [ ] 单页 + 双页（含孤页）都覆盖（buildSinglePage 是共用 helper，两路径都受益）

## Step 2 — Fix Bug B1：ScrollToOffsetService 双页 spread 索引换算

**文件 A**: `app/lib/features/reader/services/scroll_to_offset.dart`

**改动**：`scrollToCharacterOffset` 加 `bool dualPageMode = false` 参数；paged 分支换算。

```dart
static Future<void> scrollToCharacterOffset({
  required ScrollableState scrollable,
  required int targetOffset,
  required PaginationMode paginationMode,
  List<PageBreak> pageBreaks = const [],
  PageController? pageController,
  // M2.10/Bug B1: 双页模式下 PageController.page 是 spread 索引（PageView
  // itemCount = (breaks+1)~/2），而 _findPageForOffset 返回 break 索引。
  // 不换算则 jumpToPage(breakIdx) 在 breakIdx >= spreadCount 时抛 assertion
  // → 笔记/摘录跳转崩溃。调用方从 engine.dualPageMode 传入。
  bool dualPageMode = false,
  Duration duration = const Duration(milliseconds: 300),
}) async {
  // ... scroll 分支不变 ...
  // paged 分支:
  final breakIdx = _findPageForOffset(pageBreaks, targetOffset);
  final targetPage = dualPageMode ? breakIdx ~/ 2 : breakIdx;
  pageController.jumpToPage(targetPage);
}
```

**文件 B**: `app/lib/features/reader/pages/reader_body.dart`

**改动**：两个调用点传 `dualPageMode`。

- `_maybeHandleInitialLocator`（~line 195）：
