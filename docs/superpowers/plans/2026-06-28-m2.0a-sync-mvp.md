# M2.0a Sync MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver single-direction sync (push + pull, last-write-wins per record) for highlights/notes/reading-progress/book-metadata between devices via 坚果云 WebDAV.

**Architecture:**
- New drift table `SyncOutbox` (schema v6) queues local writes as JSON envelopes (`SyncRecord`).
- `WebDavClient` (HTTP-based) does PROPFIND/GET/PUT against `https://dav.jianguoyun.com/dav/`.
- `WebDavSyncEngine` reads outbox → uploads `/zhiyue/snapshots/{deviceId}.jsonl` (JSON Lines, per-device file), and pulls other devices' files → applies to local DB with last-write-wins per record (by `mtime`).
- Repositories call `SyncOutboxDao.enqueue(...)` after each write; outbox is the source of truth for what needs pushing.
- `flutter_secure_storage` stores 坚果云 credentials + deviceId (Windows DPAPI / Android Keystore).
- Rate limiter enforces ≥2s between WebDAV requests (R1: 坚果云 30 req/min limit).

**Tech Stack:**
- Existing: drift (schema bump v5→v6), riverpod, go_router
- New deps: `http: ^1.2.0` (WebDAV HTTP), `flutter_secure_storage: ^9.2.2` (credentials)
- Test: `mocktail` (already dev_dep), `http.MockClient` for WebDAV

**Reference spec:** `docs/superpowers/specs/2026-06-28-phase2-roadmap-design.md` §3 Spiral 1

**Risks (from spec §4):** R1 (WebDAV rate limit) → rate limiter; R5 (Chinese paths) → ASCII-only test fixtures; R6 (data loss) → tombstone records + last-write-wins + conflict log in S3.

```dart
import 'package:meta/meta.dart';

/// Syncable record types. The string names are stable across versions —
/// do NOT rename, or pull from older clients will fail.
enum SyncRecordType {
  book,
  bookNote,
  annotation,
  readingProgress,
}

/// JSON envelope persisted in outbox + shipped over WebDAV.
///
/// One file per device (`/zhiyue/snapshots/{deviceId}.jsonl`) holds JSON Lines
/// of these records. Receivers diff by `id`+`type` and apply last-write-wins
/// using `mtime`.
@immutable
class SyncRecord {
  final String id;
  final SyncRecordType type;
  final DateTime mtime;
  final bool deleted;
  final Map<String, dynamic> payload;

  const SyncRecord({
    required this.id,
    required this.type,
    required this.mtime,
    required this.deleted,
    required this.payload,
  });

  /// Tombstone for deletions — empty payload, deleted=true.
  factory SyncRecord.tombstone({
    required String id,
    required SyncRecordType type,
    required DateTime mtime,
  }) {
    return SyncRecord(
      id: id,
      type: type,
      mtime: mtime,
      deleted: true,
      payload: const {},
    );
  }

  factory SyncRecord.fromJson(Map<String, dynamic> json) {
    return SyncRecord(
      id: json['id'] as String,
      type: SyncRecordType.values.byName(json['type'] as String),
      mtime: DateTime.parse(json['mtime'] as String),
      deleted: json['deleted'] as bool,
      payload: Map<String, dynamic>.from(json['payload'] as Map),
    );
  }

  Map<String, dynamic> toJson() {
    return {
      'id': id,
      'type': type.name,
      'mtime': mtime.toUtc().toIso8601String(),
      'deleted': deleted,
      'payload': payload,
    };
  }
}
```

```dart
import 'package:drift/drift.dart';

import '../database.dart';
import '../tables/sync_outbox.dart';

part 'sync_outbox_dao.g.dart';

@DriftAccessor(tables: [SyncOutbox])
class SyncOutboxDao extends DatabaseAccessor<AppDatabase>
    with _$SyncOutboxDaoMixin {
  SyncOutboxDao(super.db);

  /// Queue a record for sync push. Returns the auto-increment row id.
  Future<int> enqueue({
    required String recordId,
    required String recordType,
    required String payloadJson,
    DateTime? queuedAt,
  }) {
    return into(syncOutbox).insert(
      SyncOutboxCompanion.insert(
        recordId: recordId,
        recordType: recordType,
        payloadJson: payloadJson,
        queuedAt: queuedAt == null ? const Value.absent() : Value(queuedAt),
      ),
    );
  }

  /// All rows with pushed_at IS NULL, ordered oldest-first.
  Future<List<SyncOutboxData>> getPending() {
    return (select(syncOutbox)
          ..where((t) => t.pushedAt.isNull())
          ..orderBy([(t) => OrderingTerm.asc(t.queuedAt)]))
        .get();
  }

  Future<void> markPushed(int id, DateTime ts) {
    return (update(syncOutbox)..where((t) => t.id.equals(id)))
        .write(SyncOutboxCompanion(pushedAt: Value(ts)));
  }

  /// Delete pushed rows older than the cutoff. Returns count removed.
  /// Called by a periodic cleanup task (not in M2.0a MVP — exposed for tests).
  Future<int> purgePushedBefore(DateTime cutoff) {
    return (delete(syncOutbox)
          ..where((t) => t.pushedAt.isNotNull() & t.pushedAt.isSmallerThanValue(cutoff)))
        .go();
  }
}
```

```dart
import 'dart:async';

/// Serializes calls with a minimum interval between them.
///
/// Used for WebDAV requests to stay under 坚果云's 30 req/min limit (R1).
/// Calls are FIFO — a single underlying queue ensures no two calls overlap.
class RateLimiter {
  RateLimiter({required this.minInterval});

  final Duration minInterval;
  DateTime? _lastCompletedAt;
  Future<void>? _queueTail;

  /// Runs [action] after waiting for the minimum interval since the last
  /// completion. Returns the result of [action].
  Future<T> run<T>(Future<T> Function() action) {
    final completer = Completer<T>();
    final previous = _queueTail ?? Future<void>.value();
    _queueTail = previous.then((_) async {
      final now = DateTime.now();
      final elapsed = _lastCompletedAt == null
          ? minInterval
          : now.difference(_lastCompletedAt!);
      if (elapsed < minInterval) {
        await Future.delayed(minInterval - elapsed);
      }
      try {
        final result = await action();
        _lastCompletedAt = DateTime.now();
        completer.complete(result);
      } catch (e, st) {
        _lastCompletedAt = DateTime.now();
        completer.completeError(e, st);
      }
    });
    return completer.future;
  }
}
```

```dart
import 'package:flutter_secure_storage/flutter_secure_storage.dart';

/// Encrypted storage for sync credentials + deviceId.
///
/// Keys are namespaced under `zhiyue.sync.*`. Storage backend:
/// - Windows: DPAPI under user account
/// - Android: Keystore
/// - iOS: Keychain
class SyncCredentials {
  SyncCredentials([FlutterSecureStorage? storage])
      : _storage = storage ?? const FlutterSecureStorage();

  static const _kUsername = 'zhiyue.sync.username';
  static const _kPassword = 'zhiyue.sync.password';
  static const _kDeviceId = 'zhiyue.sync.deviceId';

  final FlutterSecureStorage _storage;

  Future<void> save({
    required String username,
    required String password,
    required String deviceId,
  }) async {
    await _storage.write(key: _kUsername, value: username);
    await _storage.write(key: _kPassword, value: password);
    await _storage.write(key: _kDeviceId, value: deviceId);
  }

  Future<({String? username, String? password, String? deviceId})> load() async {
    return (
      username: await _storage.read(key: _kUsername),
      password: await _storage.read(key: _kPassword),
      deviceId: await _storage.read(key: _kDeviceId),
    );
  }

  Future<void> clear() async {
    await _storage.delete(key: _kUsername);
    await _storage.delete(key: _kPassword);
    await _storage.delete(key: _kDeviceId);
  }
}
```

```dart
import 'dart:convert';

import 'package:http/http.dart' as http;

/// Thrown when WebDAV returns a non-success status.
class WebDavException implements Exception {
  WebDavException(this.statusCode, this.path, this.body);
  final int statusCode;
  final String path;
  final String body;

  @override
  String toString() => 'WebDavException($statusCode at $path): $body';
}

/// Minimal WebDAV HTTP client (PROPFIND / GET / PUT / DELETE).
///
/// Constructor accepts an [httpClient] for testability — production passes
/// nothing (uses default) and tests inject `http.MockClient`.
class WebDavClient {
  WebDavClient({
    required this.baseUrl,
    required this.username,
    required this.password,
    http.Client? httpClient,
  }) : _httpClient = httpClient ?? http.Client();

  /// Base URL up to (and including) the user-specific path segment,
  /// e.g. `https://dav.jianguoyun.com/dav/user@example.com`.
  final String baseUrl;
  final String username;
  final String password;
  final http.Client _httpClient;

  Uri _uri(String path) {
    final clean = path.startsWith('/') ? path : '/$path';
    return Uri.parse('$baseUrl$clean');
  }

  Map<String, String> get _authHeader {
    final credentials = base64Encode(utf8.encode('$username:$password'));
    return {'authorization': 'Basic $credentials'};
  }

  /// PROPFIND on a directory, return list of file names (not directories).
  Future<List<String>> listFiles(String dirPath) async {
    final response = await _httpClient.send(http.Request('PROPFIND', _uri(dirPath))
      ..headers['authorization'] = _authHeader['authorization']!
      ..headers['depth'] = '1'
      ..headers['content-type'] = 'application/xml; charset=utf-8'
      ..body = '''<?xml version="1.0" encoding="utf-8"?>
<D:propfind xmlns:D="DAV:"><D:prop><D:getcontentlength/></D:prop></D:propfind>''');
    final body = await response.stream.bytesToString();
    if (response.statusCode != 207) {
      throw WebDavException(response.statusCode, dirPath, body);
    }
    return _parsePropfindFilenames(body);
  }

  /// GET a file's content as UTF-8 string.
  Future<String> getString(String path) async {
    final response = await _httpClient.get(_uri(path), headers: _authHeader);
    _ensureOk(response.statusCode, path, response.body);
    return response.body;
  }

  /// PUT a string to a file. Creates or overwrites.
  Future<void> putString(String path, String body) async {
    final response = await _httpClient.put(
      _uri(path),
      headers: _authHeader,
      body: body,
    );
    _ensureOk(response.statusCode, path, response.body);
  }

  /// DELETE a file. No-op (returns silently) if the file doesn't exist (404).
  Future<void> delete(String path) async {
    final response = await _httpClient.delete(_uri(path), headers: _authHeader);
    if (response.statusCode != 204 && response.statusCode != 404) {
      throw WebDavException(response.statusCode, path, response.body);
    }
  }

  void _ensureOk(int status, String path, String body) {
    if (status < 200 || status >= 300) {
      throw WebDavException(status, path, body);
    }
  }

  /// Extract `<D:href>` values from multistatus response and return the
  /// trailing path segment (the file name).
  List<String> _parsePropfindFilenames(String xmlBody) {
    final result = <String>[];
    final hrefRegex = RegExp(r'<(?:D|d):href>([^<]+)</(?:D|d):href>');
    for (final match in hrefRegex.allMatches(xmlBody)) {
      final href = Uri.decodeFull(match.group(1)!);
      final segments = href.split('/').where((s) => s.isNotEmpty).toList();
      if (segments.isEmpty) continue;
      final last = segments.last;
      // Skip directory entries (href ends with /) and the dir itself.
      if (last.endsWith('.jsonl')) {
        result.add(last);
      }
    }
    return result;
  }
}
```

```dart
/// Result of a full sync cycle (push + pull).
class SyncResult {
  const SyncResult({
    required this.success,
    required this.pushedCount,
    required this.pulledCount,
    required this.error,
  });

  const SyncResult.success({
    required int pushedCount,
    required int pulledCount,
  }) : this(
          success: true,
          pushedCount: pushedCount,
          pulledCount: pulledCount,
          error: null,
        );

  const SyncResult.failure(String error)
      : this(success: false, pushedCount: 0, pulledCount: 0, error: error);

  final bool success;
  final int pushedCount;
  final int pulledCount;
  final String? error;
}

/// Thrown when sync fails — caller wraps in SyncResult.failure.
class SyncException implements Exception {
  const SyncException(this.message);
  final String message;

  @override
  String toString() => 'SyncException: $message';
}

/// Abstract sync engine. M2.0a ships one implementation (WebDavSyncEngine);
```

```dart
import 'dart:convert';

import 'package:zhiyue/data/local/daos/sync_outbox_dao.dart';
import 'package:zhiyue/data/local/database.dart';
import 'package:zhiyue/services/sync/rate_limiter.dart';
import 'package:zhiyue/services/sync/sync_engine.dart';
import 'package:zhiyue/services/sync/web_dav_client.dart';

/// WebDAV-backed implementation of [SyncEngine].
///
/// Push: read all pending outbox rows, fetch the existing per-device
/// snapshot file (JSON Lines), append the new records, write it back.
/// Each appended line is the JSON envelope of a SyncRecord.
///
/// Pull: implemented in Task 11.
class WebDavSyncEngine implements SyncEngine {
  WebDavSyncEngine({
    required this.database,
    required this.outbox,
    required this.webdav,
    required this.deviceId,
    Duration? rateLimiterInterval,
  }) : _rateLimiter = RateLimiter(
          minInterval: rateLimiterInterval ?? const Duration(seconds: 2),
        );

  final AppDatabase database;
  final SyncOutboxDao outbox;
  final WebDavClient webdav;
  final String deviceId;
  final RateLimiter _rateLimiter;

  String get _snapshotPath => '/zhiyue/snapshots/$deviceId.jsonl';

  /// Push-only entry point. Used by tests and by [sync] internally.
  Future<SyncResult> pushOnly() async {
    final pending = await outbox.getPending();
    if (pending.isEmpty) {
      return const SyncResult.success(pushedCount: 0, pulledCount: 0);
    }

    String existing = '';
    try {
      existing = await _rateLimiter.run(() => webdav.getString(_snapshotPath));
    } on WebDavException catch (e) {
      if (e.statusCode != 404) rethrow;
      // 404 = file doesn't exist yet, treat as empty
    }

    // Append new lines.
    final lines = <String>[];
    if (existing.isNotEmpty) {
      lines.addAll(existing.split('\n').where((l) => l.trim().isNotEmpty));
    }
    for (final row in pending) {
      lines.add(row.payloadJson);
    }
    final newBody = '${lines.join('\n')}\n';

    await _rateLimiter.run(() => webdav.putString(_snapshotPath, newBody));

    final now = DateTime.now();
    for (final row in pending) {
      await outbox.markPushed(row.id, now);
    }

    return SyncResult.success(pushedCount: pending.length, pulledCount: 0);
  }

  @override
  Future<SyncResult> sync() async {
    // Full implementation in Task 11 (push + pull).
    return pushOnly();
  }
}
```

```dart
  /// Pull-only entry point. Fetches all device snapshots and applies them.
  Future<SyncResult> pullOnly() async {
    final applier = RemoteRecordApplier(database);
    final List<String> files;
    try {
      files = await _rateLimiter.run(
          () => webdav.listFiles('/zhiyue/snapshots/'));
    } on WebDavException catch (e) {
      if (e.statusCode == 404) {
        // Directory doesn't exist yet — no remote data.
        return const SyncResult.success(pushedCount: 0, pulledCount: 0);
      }
      rethrow;
    }

    var applied = 0;
    for (final file in files) {
      if (file == '$deviceId.jsonl') continue; // skip own file
      final body = await _rateLimiter.run(
          () => webdav.getString('/zhiyue/snapshots/$file'));
      final lines = body.split('\n').where((l) => l.trim().isNotEmpty);
      for (final line in lines) {
        try {
          final json = jsonDecode(line) as Map<String, dynamic>;
          final record = SyncRecord.fromJson(json);
          final didApply = await applier.apply(record);
          if (didApply) applied++;
        } catch (_) {
          // Skip malformed line — don't fail entire sync.
        }
      }
    }
    return SyncResult.success(pushedCount: 0, pulledCount: applied);
  }

  @override
  Future<SyncResult> sync() async {
    final pushResult = await pushOnly();
    if (!pushResult.success) return pushResult;
    final pullResult = await pullOnly();
    return SyncResult(
      success: pullResult.success,
      pushedCount: pushResult.pushedCount,
      pulledCount: pullResult.pulledCount,
      error: pullResult.error,
    );
  }
```

```dart
import 'package:flutter_riverpod/flutter_riverpod.dart';

import 'package:zhiyue/data/local/database.dart';
import 'package:zhiyue/services/sync/sync_credentials.dart';

import 'package:zhiyue/services/sync/web_dav_client.dart';
import 'package:zhiyue/services/sync/web_dav_sync_engine.dart';

import '../models/sync_status.dart';

class SyncState {
  const SyncState({
    this.status = SyncStatus.idle,
    this.lastSyncAt,
    this.lastMessage,
    this.lastPushedCount = 0,
    this.lastPulledCount = 0,
  });

  final SyncStatus status;
  final DateTime? lastSyncAt;
  final String? lastMessage;
  final int lastPushedCount;
  final int lastPulledCount;

  SyncState copyWith({
    SyncStatus? status,
    DateTime? lastSyncAt,
    String? lastMessage,
    int? lastPushedCount,
    int? lastPulledCount,
  }) {
    return SyncState(
      status: status ?? this.status,
      lastSyncAt: lastSyncAt ?? this.lastSyncAt,
      lastMessage: lastMessage ?? this.lastMessage,
      lastPushedCount: lastPushedCount ?? this.lastPushedCount,
      lastPulledCount: lastPulledCount ?? this.lastPulledCount,
    );
  }
}

class SyncController extends StateNotifier<SyncState> {
  SyncController({
    required this.database,
    required this.credentials,
  }) : super(const SyncState());

  final AppDatabase database;
  final SyncCredentials credentials;

  SyncEngine? _engine;

  /// Build the engine on demand, after credentials are confirmed present.
  Future<SyncEngine?> _buildEngine() async {
    final creds = await credentials.load();
    if (creds.username == null || creds.password == null || creds.deviceId == null) {
      return null;
    }
    final baseUrl = 'https://dav.jianguoyun.com/dav/${creds.username}';
    final webdav = WebDavClient(
      baseUrl: baseUrl,
      username: creds.username!,
      password: creds.password!,
    );
    return WebDavSyncEngine(
      database: database,
      outbox: database.syncOutboxDao,
      webdav: webdav,
      deviceId: creds.deviceId!,
    );
  }

  Future<void> saveCredentials({
    required String username,
    required String password,
  }) async {
    final existing = await credentials.load();
    final deviceId = existing.deviceId ?? const Uuid().v4();
    await credentials.save(
      username: username,
      password: password,
      deviceId: deviceId,
    );
  }

  Future<void> clearCredentials() async {
    await credentials.clear();
    _engine = null;
  }

  Future<bool> hasCredentials() async {
    final c = await credentials.load();
    return c.username != null && c.password != null;
  }

  Future<void> syncNow() async {
    final engine = _engine ?? await _buildEngine();
    if (engine == null) {
      state = state.copyWith(
        status: SyncStatus.error,
        lastMessage: 'syncCredentialsMissing',
      );
      return;
    }
    _engine = engine;

    state = state.copyWith(status: SyncStatus.pushing);
    try {
      final result = await engine.sync();
      state = SyncState(
        status: result.success ? SyncStatus.success : SyncStatus.error,
        lastSyncAt: DateTime.now(),
        lastMessage: result.error,
        lastPushedCount: result.pushedCount,
        lastPulledCount: result.pulledCount,
      );
    } on WebDavException catch (e) {
      state = state.copyWith(
        status: SyncStatus.error,
        lastSyncAt: DateTime.now(),
        lastMessage: e.statusCode == 429 ? 'syncRateLimitedWarning' : e.toString(),
      );
    } catch (e) {
      state = state.copyWith(
        status: SyncStatus.error,
        lastSyncAt: DateTime.now(),
        lastMessage: e.toString(),
      );
    }
  }
}
```

```dart
      'INSERT INTO annotations(id, book_note_id, locator, quote, color, tags, source, updated_at) VALUES(?, ?, ?, ?, ?, ?, ?, ?)',
      variables: [
        Variable.withString('a1'), Variable.withString('bn1'),
        Variable.withString('{}'), Variable.withString('highlight from A'),
        Variable.withString('yellow'), Variable.withString('[]'),
        Variable.withString('manual'),
        Variable.withDateTime(DateTime.utc(2026, 6, 28, 10)),
      ],
    );

    // 2. Enqueue via SyncRecorder (simulating the repo hook).
    final recorder = SyncRecorder(SyncOutboxDao(dbA));
    await recorder.recordAnnotation(
      id: 'a1',
      bookNoteId: 'bn1',
      locatorJson: '{}',
      quote: 'highlight from A',
      note: null,
      color: 'yellow',
      tagsJson: '[]',
      source: 'manual',
      mtime: DateTime.utc(2026, 6, 28, 10),
    );

    // 3. Simulate the cloud: device A's PUT body is captured, then served
    //    to device B's GET + listFiles.
    String? pushedBody;
    when(() => webdavA.getString(any())).thenAnswer((_) async => '');
    when(() => webdavA.putString(any(), any()))
        .thenAnswer((inv) async {
      pushedBody = inv.positionalArguments[1] as String;
    });

    await engineA.pushOnly();
    expect(pushedBody, isNotNull);
    expect(pushedBody!, contains('"id":"a1"'));

    // 4. Device B sees only device-A.jsonl file; pulls it.
    when(() => webdavB.listFiles('/zhiyue/snapshots/'))
        .thenAnswer((_) async => ['device-A.jsonl']);
    when(() => webdavB.getString('/zhiyue/snapshots/device-A.jsonl'))
        .thenAnswer((_) async => pushedBody!);
    when(() => webdavB.getString('/zhiyue/snapshots/device-B.jsonl'))
        .thenAnswer((_) async => '');

    final result = await engineB.pullOnly();
    expect(result.pulledCount, 1);

    // 5. Verify dbB has the annotation + the cascading books/book_notes rows
    //    were created by RemoteRecordApplier (annotation needs bn1 to exist).
    //    For MVP test, pre-seed dbB with the FK rows (matching what sync
    //    would also need to pull). In a full impl, books + bookNotes are
    //    synced first; here we just verify the annotation row.
    final annotations = await dbB.customSelect(
      'SELECT quote FROM annotations WHERE id = ?',
      variables: [Variable.withString('a1')],
    ).get();
    expect(annotations, hasLength(1));
    expect(annotations.first.data['quote'], 'highlight from A');
  });
}
```

Note: this test pre-seeds book + book_note in dbB before pulling — a fuller test would sync those records first. The MVP scope verifies the annotation write-through, push, pull, and apply loop.

```markdown
## 关键技术决策

1. **JSON Lines per-device file**（`/zhiyue/snapshots/{deviceId}.jsonl`）：避免多端写同一文件；append-only 模式简单可靠。
2. **last-write-wins per record**（by `mtime`）：MVP 不做 merge；冲突日志推到 M2.0b。
3. **抽象 SyncEngine interface + 单一 WebDavSyncEngine impl**：YAGNI 边界，Dropbox/OneDrive 等 provider 推到未来。
4. **flutter_secure_storage**：Windows DPAPI / Android Keystore 自动选；不写日志。
5. **RateLimiter**：FIFO 队列 + minInterval 字段，封装在 WebDavSyncEngine 内。
6. **SyncRecorder 解耦**：repositories 接 `SyncRecorder?`（可空），单元测试传 null 跳过 sync 副作用。
7. **drift customStatement 而非 generated API**：RemoteRecordApplier 用 raw SQL INSERT OR REPLACE，绕过 drift 的 generated companion 类型摩擦。
```
