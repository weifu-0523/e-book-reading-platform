## Batch 1 (B1): 翻页 + 分页 + 键盘 + ESC

**Files:**
- Modify: `reader_engine_epub_view/lib/epubx_renderer.dart`（nextPage/previousPage 章内分页 + 章末换章；Paginator 传 marginPx）
- Modify: `reader_engine/lib/engine/reader_engine.dart`（接口加 nextPage/previousPage）
- Modify: `reader_engine_epub_view/lib/concrete_reader_engine.dart`（透传）
- Modify: `reader_engine_pdf_view/lib/pdf_reader_engine.dart`（PDF 委托 nextSpine）
- Modify: `app/lib/features/reader/pages/reader_body.dart`（tap zone 按 paginationMode 路由）
- Modify: `reader_engine_epub_view/lib/paginator.dart`（marginPx 参数扣上下/左右）
- Modify: `app/lib/features/reader/widgets/reader_scaffold.dart`（HardwareKeyboard 全局监听）
- Modify: 7 个 test fake（加 nextPage/previousPage stub）

**Background:** Bug #6（翻页乱翻/延迟）+ #8（文字溢出）+ #9（ESC）。根因：tap zone 无条件调 nextSpine（章末才换章，章内不分页）；Paginator 测量不扣 margin 导致每页溢出；SelectableRegion 抢焦导致 ReaderScaffold Focus 收不到键盘事件。

- [x] **Step 1: nextPage/previousPage 章内分页**
  - `EpubxRenderer.nextPage()`：读 `_pageController.page`，章末（`>= breaks.length-1`）换章，否则 `_pageController.nextPage(200ms)`
  - `previousPage()`：章首（`page <= 0`）换上一章，否则 `previousPage`
  - 接口 `ReaderEngine` 加 `bool nextPage()` / `bool previousPage()`
- [x] **Step 2: tap zone 按 paginationMode 路由**
  - reader_body onTapPrev/onTapNext：paged → engine.previousPage/nextPage；scroll → previousSpine/nextSpine
- [x] **Step 3: Paginator 扣 margin**
  - `usableHeight = viewport.height - 2*marginPx`；`usableWidth = (viewport.width - 2*marginPx).clamp(50, inf)`
  - `_CacheKey` 加 marginPx 字段
- [x] **Step 4: HardwareKeyboard 全局监听（Bug #9 ESC）**
  - `initState` 加 `HardwareKeyboard.instance.addHandler(_handleHardwareKeyEvent)`
  - `dispose` 移除；Focus.onKeyEvent 移除（避免双重派发）

**Verification:** 用户确认"鼠标翻页灵敏、每页正常显示、文字不溢出、键盘左右键翻页 OK、ESC 退全屏 OK"。94 reader widget + 5 fullscreen 测试通过。

## Batch 2 (B2): 跨章翻页修复

**Files:**

- [x] **Step 1: setChapter emit ReaderEngineReady**

  - 新增 `_maybeApplyPendingLastPageJump()`：`_cachedBreaks` 填充后 jumpToPage 到末页（one-shot）

  - `setChapter` 清零 flag（仅 previousPage 重新 arm）
- [x] **Step 3: 回归测试**

## Batch 3 (B3): 高亮渲染（paged 模式）

**Files:**
- New: `reader_engine_epub_view/lib/html_slicer.dart`
- Modify: `reader_engine_epub_view/lib/epubx_renderer.dart`（_buildPaged 改 HtmlWidget）
- Test: `reader_engine_epub_view/test/html_slicer_test.dart`（NEW，18 cases）
- Test: `reader_engine_epub_view/test/epubx_renderer_paged_highlight_test.dart`（NEW，3 cases）

**Background:** Bug #5b（标记颜色后文字不变色）+ #5（改淡化底色）。根因：`_buildPaged` 用 `Text(plain.substring(start,end))` 渲染每页，丢掉了 `HtmlHighlightInjector` 注入的 `<span style="background-color:...">`。即使 injectHighlights 正确写入 `_allHighlights`、currentHighlightedHtml() 正确产出含 span 的 HTML，paged 路径也丢了。#5 的淡化底色（0.4 alpha）早已在 reader_body._highlightColorRgba 满足，只是 span 进不了渲染。

- [x] **Step 1: HtmlSlicer 工具**
  - `sliceByPlainRange(html, pageStart, pageEnd)`：DOM 遍历，保留祖先标签，裁剪部分重叠文本节点，删除范围外文本节点
  - `localizeHighlights(highlights, pageStart, pageEnd)`：全局高亮 plain offset → 页面本地坐标（求交集 + 平移）
- [x] **Step 2: _buildPaged 改用 HtmlWidget**
  - 每页：`HtmlSlicer.sliceByPlainRange` → `HtmlHighlightInjector.inject`（页面本地高亮）→ `HtmlWidget`
  - build() 重构：scroll 用 currentHighlightedHtml()（整章注入），paged 传 raw HTML（按页注入）
- [x] **Step 3: 测试**
  - HtmlSlicer 18 cases（slice + localize 边界）；paged 高亮 3 cases（HtmlWidget 渲染 + 高亮 span 存在 + 无高亮无回归）

**Verification:** 用户确认"基本验收"。115 epub_view 测试通过。副带收益：paged 模式恢复富文本格式（粗体/标题/段落）。

## Batch 4 (B4): 书签红屏 + 笔记延迟

- [x] **Step 3: gotoLocator 跨章分支补 jumpToPage(0)**

- [x] **Step 5: 测试**

## M2.9: EPUB 双页布局 + 每页页码

**Files:**
- Modify: `reader_engine_epub_view/lib/epubx_renderer.dart`（_buildPaged 双页分支 + setDualPageMode + spread getters + nextPage/previousPage/maybeEmit/pendingJump 用 spreadCount）
- Modify: `reader_engine/lib/engine/reader_engine.dart`（接口加 dualPageMode/currentSpreadCount/currentSpreadIndex）

- Modify: `app/lib/features/reader/pages/reader_body.dart`（LayoutBuilder 触发双页）
- Modify: `app/lib/features/reader/pages/reader_progress_bar.dart`（页码计算）
- Modify: `app/lib/features/reader/widgets/reader_bottom_bar.dart`（pageInfo 字段）
- Modify: 7 个 test fake（加 3 个接口成员）
- Test: `reader_engine_epub_view/test/epubx_renderer_dual_page_test.dart`（重写，10 cases）

**Background:** 需求"页面足够大时像书一样分左右两页 + 每页下方显示页码"。M2.5/T14 早留了 `dualPageMode` API surface 但渲染层推到 v1.6。本次实现真正渲染。设计决策（用户确认）：宽屏（≥1100px）自动触发；页码显示"本章 当前/总"（如 `3 / 12`，双页 `3-4 / 12`）。

- [x] **Step 1: dualPageMode 改 private + setDualPageMode**
  - `_dualPageMode` private；`dualPageMode` getter；`setDualPageMode(value)` 清缓存 + jumpToPage(0) + emit state
  - 新增 `currentSpreadCount`（双页 = (breaks+1)~/2，单页 = breaks.length）/ `currentSpreadIndex`
- [x] **Step 2: _buildPaged 双页渲染分支**
  - measureWidth = dualPageMode ? (rawWidth - 24) / 2 : rawWidth（24px 书脊 gutter）
  - PageView itemCount = dualPageMode ? (breaks+1)~/2 : breaks.length
  - itemBuilder：dualPageMode → Row(Expanded(buildSinglePage(leftIdx)), SizedBox(24), Expanded(buildSinglePage(rightIdx) ?? SizedBox.shrink))
  - buildSinglePage 抽出共用：sliceByPlainRange + 高亮注入 + HtmlWidget
- [x] **Step 3: 翻页/章末/末页定位用 spreadCount**
  - nextPage/previousPage 章末判定：`currentPage >= currentSpreadCount - 1`
  - _maybeEmitChapterEnd：同上
  - _maybeApplyPendingLastPageJump：jumpToPage(currentSpreadCount - 1)
- [x] **Step 4: onPageChanged 加 _emitCurrentLocation（页码实时更新前置）**
  - 旧 `onPageChanged: (_) => _maybeEmitChapterEnd()` → 改为同时调 `_emitCurrentLocation()`，翻页时位置流 emit → ReaderProgressBar 刷新页码
- [x] **Step 5: ReaderBottomBar 加 pageInfo**
  - 新增可选 `String? pageInfo`，有值时替代百分比显示
- [x] **Step 6: ReaderProgressBar 计算 _epubPageInfo**
  - EPUB paged：单页 `${idx+1} / $total`；双页 `${left}-${right} / $totalCols`（孤页只显左）
  - PDF/scroll：null（回退百分比）
- [x] **Step 7: reader_body LayoutBuilder 触发双页**
  - `engine is ConcreteEpubReaderEngine && paginationMode == paged` → `setDualPageMode(isWide)`
  - 接口 3 成员加到 ReaderEngine，PDF 中性实现，7 个 fake 更新
- [x] **Step 8: 测试**
  - 10 cases：双页渲染 Row+2 HtmlWidget、单页 1 HtmlWidget、spreadCount halving、孤页不崩、setDualPageMode reset page、idempotent

**Verification:** analyze 0 error；125 epub_view + 103 reader 测试通过；exe 重建（7月4日 02:11）。

**关键风险记录:**
1. **测量 vs 渲染高度差**：Paginator 用 TextPainter 测 plain，HtmlWidget 渲染 rich。双页 halve 宽度后换行更多，误差可能放大。沿用现有策略（<1 行可接受），M3 精确化改 HtmlWidget 测量。
2. **双页下文字选择**：保留 SelectableRegion（不像 PDF 禁用），跨页选择可能行为怪异。先不限制，用户反馈再优化。
3. **窗口缩放单↔双切换**：缓存 key 含 viewport Size 自动失效；setDualPageMode 内 jumpToPage(0) 防 page 越界。

**不做的事:**
- 不持久化 dualPageMode（与 PDF 一致，v1.5.2 再做）
- 不做全书累计页码（性能开销大，用户选了本章页码）
- 不改 PDF 双页（已实现）
- 不做双页下书脊阴影/装订线美化（纯功能，美化留后续）
