**Background**：MD 卡在 markdown 标准库产出嵌套结构 + `<br>`，Paginator 测不准。TXT 每行独立成 `<p>` 工作。仿 TXT：每行独立成 `<p>`，行内语法轻量保留，走默认 paged + 双页。

## Task 3 — EPUB `_buildPaged` O(N²) → O(N) DOM 解析

**Files**:
- `reader_engine_epub_view/lib/html_slicer.dart`
- `reader_engine_epub_view/lib/epubx_renderer.dart`

**Background**：`HtmlSlicer.sliceByPlainRange` 每次调用都 `HtmlParser(html).parse()` 整章 DOM。`_buildPaged` 的 LayoutBuilder 对每个 break 调用一次 → 单帧 O(N × 整章 DOM)。改为整章解析一次，所有 break 复用同一 doc。

**Steps**:

- [ ] **3.1** `html_slicer.dart` 重构 `_walkAndFilter` 为**非破坏式**——不修改原 doc，而是**返回一个新构造的节点列表**（深拷贝范围内节点）：
  - 新方法 `static Document _filterToNewDocument(Document source, int pageStart, int pageEnd)`：DFS 遍历 source（只读），用游标记录每个文本节点 plain 范围，命中范围的文本节点深拷贝到新 Document
  - 保留原 `_walkAndFilter`（破坏式）作为 private 实现细节或删除（取决于其他调用点）
- [ ] **3.2** 新增公共 API `static String sliceByPlainRangeDoc(Document doc, int pageStart, int pageEnd, {int? plainLength})`：接受预解析 Document，调 `_filterToNewDocument` 后返回 `newDoc.outerHtml`
- [ ] **3.3** `sliceByPlainRange(html, start, end)` 内部仍解析整章（向后兼容），委托给新 API
- [ ] **3.4** `epubx_renderer.dart:1083-1109` 改循环：
  ```dart
  // 循环外解析一次
  final chapterDoc = HtmlParser(html).parse();
  for (final el in chapterDoc.querySelectorAll('script, style')) {
    el.remove();
  }
  for (var i = 0; i < breaks.length; i++) {
    final pb = breaks[i];
    final start = pb.startOffset.clamp(0, plain.length);
    final end = pb.endOffset.clamp(start, plain.length);
    var pageHtml = HtmlSlicer.sliceByPlainRangeDoc(
      chapterDoc, start, end, plainLength: plain.length,
    );
    // ... 高亮 + 缩进注入不变
  }
  ```
- [ ] **3.5** 运行现有 `html_slicer_test.dart` 验证非破坏式实现与原破坏式行为一致
- [ ] **3.6** 新增测试：连续两次对同一 doc 切不同范围，第二次结果不受第一次影响（验证非破坏）
- [ ] **3.7** 运行 `dart.bat analyze lib/`（reader_engine_epub_view 包，按 AGENTS.md workaround 跑）+ `flutter.bat test --concurrency=1`
- [ ] **3.8** 手动验证：打开 EPUB《一本书读懂财报》（若用户能提供）或任意长章节 EPUB，翻页/目录跳转流畅

- [ ] **5.2** `local_notes_repository.dart:193-202` 重写 `watchAnnotations`：
  ```dart
  Stream<List<Annotation>> watchAnnotations(String bookId) async* {
    // BookNote 可能不存在；同时订阅两个表，BookNotes 出现后切到 Annotations
    await for (final noteRow in _notesDao.watchByBookId(bookId)) {
      if (noteRow == null) {
        yield const <Annotation>[];
        continue;

      // BookNote 已存在：切到 Annotations watch（内部 stream 永久 emit）
      yield* _annotationsDao

          .map((rows) => rows.map(_toAnnotationModel).toList());
      return;
    }
  }
  ```
