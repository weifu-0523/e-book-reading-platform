## Goal

修复 PDF 加载卡死：任意次数开任意 PDF 都能成功（或快速失败）。一行 sourceName 改动根治 PDF-1/PDF-2 系列。

## Architecture

详见 spec 根因分析。核心：

```
旧：PdfDocument.openData(_bytes!)   // sourceName = sha256(bytes)，跨会话稳定
                                    // → 命中 pdfrx _listenables cache 中 broken entry → 卡死

新：_uniqueSourceName = 'zhiyue-pdf-${DateTime.now().microsecondsSinceEpoch}'
    PdfDocument.openData(_bytes!, sourceName: _uniqueSourceName)
                                       // 每次唯一 → cache miss → 全新 listenable → 永不卡死
```

**Steps**：
- [x] `final sourceName = _uniqueSourceName ?? doc.sourceName;`（防御性 fallback）

## Risks & Mitigation

| Risk | 缓解 |
|------|------|
| microsecondsSinceEpoch 撞 key | 1 微秒精度，单用户不可能撞 |
| pdfrx 未来版本改 cache | sourceName 唯一是官方推荐用法 |
| 用户改了 PDF 文件后开 | 字节变了但每次 sourceName 都新，仍 cache miss（不影响） |
