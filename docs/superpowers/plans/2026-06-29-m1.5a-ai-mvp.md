# M1.5a AI MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship three AI guide modes (full-book / chapter / selection) backed by an OpenAI-compatible streaming client (default DeepSeek), with on-device cache, four entry points, and chapter-bullet → note integration.

**Architecture:** Mirror the `services/sync/` + `features/sync/` split from M2.0a. `services/ai/` holds the I/O-free business logic (HTTP client, key store, text extraction, truncation, prompts, orchestrator). `features/ai/` holds Riverpod state + UI (sheet, settings page). Cache lives in drift (`ai_summaries` table, schema v6→v7). No `LlmClient` abstraction — OpenAI-compatible is the standard.

**Tech Stack:** drift (schema v7), `flutter_secure_storage` (already in pubspec from M2.0a), `http` (already in pubspec), `epubx` (local fork), `pdfrx` 2.4.4, Riverpod `StateNotifier`, flutter `ToggleButtons` + `DropdownButton`.

## Spec Source

`docs/superpowers/specs/2026-06-28-m1.5a-ai-mvp-design.md` (commit `691aa0a`). Two spec assumptions are corrected inline below based on actual codebase state:

1. **Spec §3.5 said `DriftChapterTextProvider` reads from a drift `chapters` table.** Reality: there is **no** drift chapters table; chapter HTML lives only inside the reader engine. Plan T8 uses **direct file parsing** (epubx for EPUB, pdfrx for PDF) so the AI feature works from Library/Detail entries without instantiating a ReaderEngine.
2. **Spec §5.2 said "加入笔记 → NotesRepository.add(bookId, content, sourceChapter)".** Reality: `NotesRepository` has no such method and `Annotation` requires a `locator` we don't have for AI-generated bullets. Plan T15 appends to `BookNotes.keyTakeaways` JSON array via a new `BookNotesDao.appendKeyTakeaway` method — that field already exists in the schema and is the natural home for AI-sourced takeaways.

All other spec elements are implemented as written.

import 'package:drift/drift.dart';

import '../database.dart';
import '../tables/ai_summaries.dart';

part 'ai_summaries_dao.g.dart';

@DriftAccessor(tables: [AiSummaries])
class AiSummariesDao extends DatabaseAccessor<AppDatabase>
    with _$AiSummariesDaoMixin {
  AiSummariesDao(super.db);

  Future<AiSummariesData?> find({
    required String bookId,
    required String mode,
    required String sourceHash,
    required int promptVersion,
  }) {
    return (select(aiSummaries)
          ..where((t) =>
              t.bookId.equals(bookId) &
              t.mode.equals(mode) &
              t.sourceHash.equals(sourceHash) &
              t.promptVersion.equals(promptVersion))
          ..limit(1))
        .getSingleOrNull();
  }

  Future<int> insert({
    required String bookId,
    required String mode,
    required String sourceHash,
    required String summaryText,
    required String modelName,
    required String baseUrl,
    required int promptVersion,
    DateTime? generatedAt,
  }) {
    return into(aiSummaries).insert(
      AiSummariesCompanion.insert(
        bookId: bookId,
        mode: mode,
        sourceHash: sourceHash,
        summaryText: summaryText,
        modelName: modelName,
        baseUrl: baseUrl,
        promptVersion: promptVersion,
        generatedAt: generatedAt == null ? const Value.absent() : Value(generatedAt),
      ),
    );
  }

  Future<int> purgeForBook(String bookId) {
    return (delete(aiSummaries)..where((t) => t.bookId.equals(bookId))).go();
  }
}

import 'package:flutter_secure_storage/flutter_secure_storage.dart';

class ApiCredentialsDefaults {
  const ApiCredentialsDefaults._();
  static const String baseUrl = 'https://api.deepseek.com';
  static const String model = 'deepseek-chat';
}

class AiCredentials {
  const AiCredentials({
    required this.apiKey,
    required this.baseUrl,
    required this.model,
  });

  final String apiKey;
  final String baseUrl;
  final String model;
}

class ApiKeyStore {
  ApiKeyStore([FlutterSecureStorage? storage])
      : _storage = storage ?? const FlutterSecureStorage();

  static const _kApiKey = 'zhiyue.ai.apiKey';
  static const _kBaseUrl = 'zhiyue.ai.baseUrl';
  static const _kModel = 'zhiyue.ai.model';

  final FlutterSecureStorage _storage;

  Future<AiCredentials?> load() async {
    final apiKey = await _storage.read(key: _kApiKey);
    if (apiKey == null || apiKey.isEmpty) return null;
    final baseUrl = await _storage.read(key: _kBaseUrl);
    final model = await _storage.read(key: _kModel);
    return AiCredentials(
      apiKey: apiKey,
      baseUrl: (baseUrl == null || baseUrl.isEmpty)
          ? ApiCredentialsDefaults.baseUrl
          : baseUrl,
      model: (model == null || model.isEmpty)
          ? ApiCredentialsDefaults.model
          : model,
    );
  }

  Future<void> save(AiCredentials c) async {
    await _storage.write(key: _kApiKey, value: c.apiKey);
    await _storage.write(key: _kBaseUrl, value: c.baseUrl);
    await _storage.write(key: _kModel, value: c.model);
  }

  Future<void> clear() async {
    await _storage.delete(key: _kApiKey);
    await _storage.delete(key: _kBaseUrl);
    await _storage.delete(key: _kModel);
  }
}
```

class TokenTruncator {
  const TokenTruncator._();

  static const int defaultBudget = 8000;

  static int estimateTokens(String text) {
    var cjk = 0, other = 0;
    for (final code in text.runes) {
      if (_isCjk(code)) {
        cjk += 1;
      } else {
        other += 1;
      }
    }
    return cjk + (other ~/ 4);
  }

  static bool _isCjk(int code) => code >= 0x4E00 && code <= 0x9FFF;

  static String truncateToTokens(String text, int maxTokens) {
    if (estimateTokens(text) <= maxTokens) return text;

    final perThirdChars = maxTokens ~/ 3;
    final headEnd = perThirdChars.clamp(0, text.length);
    final tailStart = (text.length - perThirdChars).clamp(0, text.length);
    final midStart = (text.length ~/ 2 - perThirdChars ~/ 2).clamp(0, text.length);
    final midEnd = (text.length ~/ 2 + perThirdChars ~/ 2).clamp(0, text.length);

    final head = text.substring(0, headEnd);
    final mid = midEnd > midStart ? text.substring(midStart, midEnd) : '';
    final tail = tailStart < text.length ? text.substring(tailStart) : '';
    final omittedBefore = midStart - headEnd;
    final omittedAfter = tailStart - midEnd;

    final parts = <String>[head];
    if (omittedBefore > 0) {
      parts.add('...（省略 $omittedBefore 字）...');
    }
    parts.add(mid);
    if (omittedAfter > 0) {
      parts.add('...（省略 $omittedAfter 字）...');
    }
    parts.add(tail);
    return parts.join();
  }
}
```

class ChapterBulletParseResult {
  const ChapterBulletParseResult({required this.summary, required this.bullets});
  final String summary;
  final List<String> bullets;
}

class ChapterBulletParser {
  const ChapterBulletParser._();

  static final _bulletRegex = RegExp(r'^\s*[-*]\s+(.+?)\s*$');

  static ChapterBulletParseResult parse(String text) {
    if (text.trim().isEmpty) {
      return const ChapterBulletParseResult(summary: '', bullets: []);
    }
    final lines = text.split('\n');
    final summaryBuf = <String>[];
    final bullets = <String>[];
    for (final line in lines) {
      final m = _bulletRegex.firstMatch(line);
      if (m != null) {
        bullets.add(m.group(1)!.trim());
      } else if (line.trim().isNotEmpty) {
        summaryBuf.add(line.trim());
      }
    }
    final summary = summaryBuf.join(' ').trim();
    return ChapterBulletParseResult(summary: summary, bullets: bullets);
  }
}

import 'package:epubx/epubx.dart';
import 'package:pdfrx/pdfrx.dart';
import 'package:reader_engine_epub_view/plain_text_utils.dart';

import '../../data/models/book.dart';

class EmptyTextException implements Exception {
  final String message;
  const EmptyTextException(this.message);
  @override
  String toString() => 'EmptyTextException: $message';
}

abstract class BookTextExtractor {
  Future<String> extract(Book book);
}

class EpubTextExtractor implements BookTextExtractor {
  EpubTextExtractor();

  @override
  Future<String> extract(Book book) async {
    final bytes = await File(book.filePath).readAsBytes();
    final epub = await EpubReader.readBook(bytes);
    final chapters = _flatten(epub.Chapters ?? const []);
    final buf = StringBuffer();
    for (final ch in chapters) {
      final html = ch.HtmlContent ?? '';
      if (html.isEmpty) continue;
      buf.write(PlainTextUtils.htmlToPlainWithOffsets(html).$1);
      buf.write('\n');
    }
    final text = buf.toString().trim();
    if (text.isEmpty) {
      throw const EmptyTextException('EPUB has no extractable text');
    }
    return text;
  }

  List<EpubChapter> _flatten(List<EpubChapter> chapters) {
    final result = <EpubChapter>[];
    for (final c in chapters) {
      result.add(c);
      result.addAll(_flatten(c.SubChapters ?? const []));
    }
    return result;
  }
}

class PdfTextExtractor implements BookTextExtractor {
  PdfTextExtractor();

  @override
  Future<String> extract(Book book) async {
    final doc = await PdfDocument.openFile(book.filePath);
    try {
      final buf = StringBuffer();
      for (var i = 0; i < doc.pages.length; i++) {
        final raw = await doc.pages[i].loadText();
        buf.write(raw?.fullText ?? '');
        buf.write('\n');
      }
      final text = buf.toString().trim();
      if (text.isEmpty) {
        throw const EmptyTextException('PDF has no text layer (likely a scan)');
      }
      return text;
    } finally {
      doc.dispose();
    }
  }
}

BookTextExtractor extractorFor(Book book) {
  return book.format == BookFormat.epub
      ? EpubTextExtractor()
      : PdfTextExtractor();
}

import 'dart:async';
import 'dart:convert';

import 'package:http/http.dart' as http;

abstract class AiException implements Exception {
  final String message;
  const AiException(this.message);
  @override
  String toString() => '$runtimeType: $message';
}

class AiAuthException extends AiException {
  const AiAuthException(String message) : super(message);
}

class AiRateLimitException extends AiException {
  const AiRateLimitException(String message) : super(message);
}

class AiServerException extends AiException {
  const AiServerException(String message) : super(message);
}

class AiNetworkException extends AiException {
  const AiNetworkException(String message) : super(message);
}

class AiParseException extends AiException {
  const AiParseException(String message) : super(message);
}

class OpenAiCompatibleClient {
  OpenAiCompatibleClient({
    required this.baseUrl,
    required this.apiKey,
    this.model = 'deepseek-chat',
    http.Client? httpClient,
    this.timeout = const Duration(seconds: 30),
  }) : _httpClient = httpClient ?? http.Client();

  final String baseUrl;
  final String apiKey;
  final String model;
  final Duration timeout;
  final http.Client _httpClient;

  Stream<String> streamChat({required String prompt}) async* {
    final uri = Uri.parse('$baseUrl/v1/chat/completions');
    final request = http.Request('POST', uri)
      ..headers['authorization'] = 'Bearer $apiKey'
      ..headers['content-type'] = 'application/json; charset=utf-8'
      ..body = jsonEncode({
        'model': model,
        'messages': [
          {'role': 'user', 'content': prompt},
        ],
        'stream': true,
      });

    final http.StreamedResponse response;
    try {
      response = await _httpClient.send(request).timeout(timeout);
    } catch (e) {
      throw AiNetworkException('request failed: $e');
    }

    if (response.statusCode == 401 || response.statusCode == 403) {
      throw AiAuthException('HTTP ${response.statusCode}');
    }
    if (response.statusCode == 429) {
      throw const AiRateLimitException('HTTP 429');
    }
    if (response.statusCode < 200 || response.statusCode >= 300) {
      throw AiServerException('HTTP ${response.statusCode}');
    }

    await for (final chunk in response.stream.transform(utf8.decoder)) {
      for (final rawLine in chunk.split('\n')) {
        final line = rawLine.trim();
        if (!line.startsWith('data: ')) continue;
        final payload = line.substring(6).trim();
        if (payload == '[DONE]') return;
        try {
          final json = jsonDecode(payload) as Map<String, dynamic>;
          final choices = json['choices'] as List?;
          if (choices == null || choices.isEmpty) continue;
          final delta = choices[0]['delta'] as Map<String, dynamic>?;
          final content = delta?['content'];
          if (content is String && content.isNotEmpty) yield content;
        } catch (e) {
          throw AiParseException('failed to parse SSE payload: $e');
        }
      }
    }
  }
}

import 'dart:async';
import 'dart:convert';

import 'package:crypto/crypto.dart';
import 'package:http/http.dart' as http;

import '../../data/local/daos/ai_summaries_dao.dart';

enum AiGuideMode { full, chapter, selection }

enum AiGuideError {
  noApiKey,
  authFailed,
  rateLimited,
  serverError,
  network,
  emptySource,
  parseError,
  cancelled,
}

sealed class AiGuideEvent {}

class AiChunkEvent extends AiGuideEvent {
  final String chunk;
  AiChunkEvent(this.chunk);
}

class AiCompleteEvent extends AiGuideEvent {
  final String fullText;
  final bool fromCache;
  AiCompleteEvent(this.fullText, {required this.fromCache});
}

class AiErrorEvent extends AiGuideEvent {
  final AiGuideError error;
  AiErrorEvent(this.error);
}

/// Abstraction over [ApiKeyStore] for testability.
abstract class ApiKeyStoreLike {
  Future<AiCredentials?> load();
}

class AiGuide {
  AiGuide({
    required this.apiKeys,
    required this.extractorFor,
    required this.chapterTextProvider,
    required this.cache,
    http.Client? httpClient,
  }) : _httpClient = httpClient;

  final ApiKeyStoreLike apiKeys;
  final BookTextExtractor Function(Book) extractorFor;
  final ChapterTextProvider chapterTextProvider;
  final AiSummariesDao cache;
  final http.Client? _httpClient;

  bool _cancelled = false;

  Stream<AiGuideEvent> run({
    required Book book,
    required AiGuideMode mode,
    int? chapterIndex,
    String? selection,
    String? chapterTitle,
  }) async* {
    final creds = await apiKeys.load();
    if (creds == null) {
      yield AiErrorEvent(AiGuideError.noApiKey);
      return;
    }

    final sourceText = await _resolveSource(book, mode, chapterIndex, selection);
    if (sourceText == null || sourceText.trim().isEmpty) {
      yield AiErrorEvent(AiGuideError.emptySource);
      return;
    }

    final truncated = mode == AiGuideMode.selection
        ? selection!
        : TokenTruncator.truncateToTokens(sourceText, TokenTruncator.defaultBudget);
    final sourceHash = sha256.convert(utf8.encode(truncated)).toString();
    final modeKey = mode.name; // 'full' | 'chapter' | 'selection'

    final cached = await cache.find(
      bookId: book.id,
      mode: modeKey,
      sourceHash: sourceHash,
      promptVersion: PromptBuilder.promptVersion,
    );
    if (cached != null) {
      yield AiCompleteEvent(cached.summaryText, fromCache: true);
      return;
    }

    final prompt = _buildPrompt(mode, truncated, chapterTitle);
    final client = OpenAiCompatibleClient(
      baseUrl: creds.baseUrl,
      apiKey: creds.apiKey,
      model: creds.model,
      httpClient: _httpClient,
    );

    try {
      final accumulated = StringBuffer();
      await for (final chunk in _streamWithRetry(client, prompt)) {
        if (_cancelled) {
          if (accumulated.isNotEmpty) {
            await _persist(book.id, modeKey, sourceHash, accumulated.toString(),
                creds.model, creds.baseUrl);
            yield AiCompleteEvent(accumulated.toString(), fromCache: false);
          } else {
            yield AiErrorEvent(AiGuideError.cancelled);
          }
          return;
        }
        accumulated.write(chunk);
        yield AiChunkEvent(chunk);
      }
      await _persist(book.id, modeKey, sourceHash, accumulated.toString(),
          creds.model, creds.baseUrl);
      yield AiCompleteEvent(accumulated.toString(), fromCache: false);
    } on AiAuthException {
      yield AiErrorEvent(AiGuideError.authFailed);
    } on AiRateLimitException {
      yield AiErrorEvent(AiGuideError.rateLimited);
    } on AiServerException {
      yield AiErrorEvent(AiGuideError.serverError);
    } on AiParseException {
      yield AiErrorEvent(AiGuideError.parseError);
    } on AiNetworkException {
      yield AiErrorEvent(AiGuideError.network);
    }
  }

  Future<String?> _resolveSource(
      Book book, AiGuideMode mode, int? chapterIndex, String? selection) async {
    switch (mode) {
      case AiGuideMode.full:
        try {
          return await extractorFor(book).extract(book);
        } on EmptyTextException {
          return null;
        }
      case AiGuideMode.chapter:
        final path = book.filePath;
        return await chapterTextProvider.get(path, chapterIndex ?? 0);
      case AiGuideMode.selection:
        return selection;
    }
  }

  String _buildPrompt(AiGuideMode mode, String source, String? chapterTitle) {
    switch (mode) {
      case AiGuideMode.full:
        return PromptBuilder.fullBook(source);
      case AiGuideMode.chapter:
        return PromptBuilder.chapter(source, chapterTitle: chapterTitle);
      case AiGuideMode.selection:
        return PromptBuilder.selection(source, chapterTitle: chapterTitle);
    }
  }

  /// Streams chunks. Retries up to 3 times on AiNetworkException with
  /// exponential backoff (1s/2s/4s). Other exceptions propagate immediately.
  Stream<String> _streamWithRetry(
      OpenAiCompatibleClient client, String prompt) async* {
    const maxAttempts = 3;
    final delays = [Duration(seconds: 1), Duration(seconds: 2), Duration(seconds: 4)];
    for (var attempt = 0; attempt < maxAttempts; attempt++) {
      try {
        yield* client.streamChat(prompt: prompt);
        return;
      } on AiNetworkException {
        if (attempt == maxAttempts - 1) rethrow;
        await Future.delayed(delays[attempt]);
      }
    }
  }

  Future<void> _persist(
      String bookId, String mode, String hash, String text, String model, String baseUrl) {
    return cache.insert(
      bookId: bookId,
      mode: mode,
      sourceHash: hash,
      summaryText: text,
      modelName: model,
      baseUrl: baseUrl,
      promptVersion: PromptBuilder.promptVersion,
    );
  }

  void cancel() => _cancelled = true;
}

    this.mode = AiGuideMode.full,
    this.accumulatedText = '',
    this.error,
    this.fromCache = false,
    this.chapterIndex,
  });

  final AiGuideStatus status;
  final AiGuideMode mode;
  final String accumulatedText;
  final AiGuideError? error;
  final bool fromCache;
  final int? chapterIndex;

  AiStreamState copyWith({
    AiGuideStatus? status,
    AiGuideMode? mode,
    String? accumulatedText,
    AiGuideError? error,
    bool? fromCache,
    int? chapterIndex,
    bool clearError = false,
  }) {
    return AiStreamState(
      status: status ?? this.status,
      mode: mode ?? this.mode,
      accumulatedText: accumulatedText ?? this.accumulatedText,
      error: clearError ? null : (error ?? this.error),
      fromCache: fromCache ?? this.fromCache,
      chapterIndex: chapterIndex ?? this.chapterIndex,
    );
  }
}

class AiGuideController extends StateNotifier<AiStreamState> {
  AiGuideController(this._guide) : super(const AiStreamState());

  final AiGuide _guide;
  StreamSubscription<AiGuideEvent>? _sub;

  Future<void> startFullBook(Book book) => _run(
    book: book, mode: AiGuideMode.full,
  );

  Future<void> startChapter(Book book, int chapterIndex, {String? chapterTitle}) =>
      _run(book: book, mode: AiGuideMode.chapter,
          chapterIndex: chapterIndex, chapterTitle: chapterTitle);

  Future<void> startSelection(Book book, String selection, {String? chapterTitle}) =>
      _run(book: book, mode: AiGuideMode.selection,
          selection: selection, chapterTitle: chapterTitle);

  Future<void> switchMode(AiGuideMode newMode, {int? chapterIndex, String? chapterTitle}) async {
    await _sub?.cancel();
    _sub = null;
    state = const AiStreamState(status: AiGuideStatus.loading, chapterIndex: chapterIndex)
        .copyWith(mode: newMode);
    // Caller must supply book via startXxx after switchMode if not already in state.
    // For sheet-driven flow, we expect switchMode to be followed by start X within the sheet.
    // This method exists primarily for the UI toggle; restart requires the original book reference.
    // Sheet-level wiring will pass book + chapterIndex directly to startXxx.
  }

  void cancel() {
    _guide.cancel();
  }

  void clearAndCancel() {
    _sub?.cancel();
    _sub = null;
    state = const AiStreamState();
  }

  Future<void> _run({
    required Book book,
    required AiGuideMode mode,
    int? chapterIndex,
    String? selection,
    String? chapterTitle,
  }) async {
    await _sub?.cancel();
    state = AiStreamState(
      status: AiGuideStatus.loading,
      mode: mode,
      chapterIndex: chapterIndex,
    );
    final completer = Completer<void>();
    _sub = _guide.run(
      book: book,
      mode: mode,
      chapterIndex: chapterIndex,
      selection: selection,
      chapterTitle: chapterTitle,
    ).listen(
      (event) {
        switch (event) {
          case AiChunkEvent(:final chunk):
            state = state.copyWith(
              status: AiGuideStatus.streaming,
              accumulatedText: state.accumulatedText + chunk,
            );
          case AiCompleteEvent(:final fullText, :final fromCache):
            state = state.copyWith(
              status: AiGuideStatus.done,
              accumulatedText: fullText,
              fromCache: fromCache,
              clearError: true,
            );
          case AiErrorEvent(:final error):
            state = state.copyWith(
              status: AiGuideStatus.error,
              error: error,
            );
        }
      },
      onDone: () {
        if (!completer.isCompleted) completer.complete();
      },
      onError: (Object e) {
        if (!completer.isCompleted) completer.completeError(e);
      },
      cancelOnError: true,
    );
    await completer.future;
  }

  @override
  void dispose() {
    _sub?.cancel();
    super.dispose();
  }
}

## 关键技术决策

1. **三模式并列**（不是单一导读）：用户每次打开 sheet 可切模式；选区入口下 modeLocked=true 锁定。
2. **No drift chapters table**：直接用 epubx + pdfrx 读文件取章节文本，不与 ReaderEngine 耦合（让 Library/Detail 也能跑导读）。
3. **chapter mode 输出解析**：ChapterBulletParser 分离总结段 + bullet 列表；bullet 可一键加入笔记。
4. **"加入笔记" 目标是 BookNotes.keyTakeaways JSON**（不是 Annotations），因为 bullet 没有 locator，且 keyTakeaways 字段已在 schema 中。
5. **Cache key = (book_id, mode, sha256(truncated_source), prompt_version)**：改 prompt → bump promptVersion → 旧缓存自动失效。
6. **Streaming 中错误不落 cache**；用户主动取消落 partial cache（"读了多少有多少"）。
7. **网络异常自动重试 3 次**（1s/2s/4s 指数退避）；HTTP 4xx/5xx 不自动重试（怕加重 API 负担）。
8. **不抽象 LlmClient interface**：OpenAI-compatible 已是事实标准，YAGNI。
