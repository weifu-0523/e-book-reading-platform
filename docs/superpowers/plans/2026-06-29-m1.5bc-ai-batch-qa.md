# M1.5b+c AI Batch Preprocess + Book Q&A Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On book import, background-preprocess all chapters (chunking + LLM summary); enable same-book Q&A with `[ch=N]` citations that jump back to the cited chapter.

**Architecture:** BookPreprocessor drives the existing AiGuide in chapter mode (no reimplemented LLM path) and writes chunks to a new `book_passages` table; BookQaService retrieves top-K chunks via substring LIKE, streams an LLM answer with `[ch=N]` markers, parses them, and tap-to-jumps via `engine.gotoTocEntry + chapterSwitchSettled`.

**Tech Stack:** Flutter 3.27 / Dart 3.10, drift 2.18, riverpod 2.5, mocktail, http, OpenAI-compatible LLM client (DeepSeek default).

```dart
  /// triggers. Same pattern as annotations_fts. Default retrieval path
  /// uses substring LIKE (CJK-friendly); FTS5 table reserved for future
  /// relevance-ranked retrieval.
  Future<void> _createBookPassagesFts5(Migrator m) async {
    await m.database.customStatement('''
      CREATE VIRTUAL TABLE IF NOT EXISTS book_passages_fts USING fts5(
        content_text, content='book_passages', content_rowid='rowid'
      )
    ''');
    await m.database.customStatement('''
      CREATE TRIGGER IF NOT EXISTS book_passages_ai AFTER INSERT ON book_passages BEGIN
        INSERT INTO book_passages_fts(rowid, content_text)
        VALUES (new.rowid, new.content_text);
      END
    ''');
    await m.database.customStatement('''
      CREATE TRIGGER IF NOT EXISTS book_passages_ad AFTER DELETE ON book_passages BEGIN
        INSERT INTO book_passages_fts(book_passages_fts, rowid, content_text)
        VALUES ('delete', old.rowid, old.content_text);
      END
    ''');
    await m.database.customStatement('''
      CREATE TRIGGER IF NOT EXISTS book_passages_au AFTER UPDATE ON book_passages BEGIN
        INSERT INTO book_passages_fts(book_passages_fts, rowid, content_text)
        VALUES ('delete', old.rowid, old.content_text);
        INSERT INTO book_passages_fts(rowid, content_text)
        VALUES (new.rowid, new.content_text);
      END
    ''');
  }
```

```dart
import 'package:drift/drift.dart';

import '../../../services/ai/book_chunker.dart';
import '../database.dart';
import '../tables/book_passages.dart';

part 'book_passages_dao.g.dart';

@DriftAccessor(tables: [BookPassages])
class BookPassagesDao extends DatabaseAccessor<AppDatabase>
    with _$BookPassagesDaoMixin {
  BookPassagesDao(super.db);

  /// Insert all [chunks] for [bookId] in a single transaction. Each chunk
  /// becomes one row; `created_at` defaults to now.
  Future<void> insertMany(String bookId, List<PassageChunk> chunks) async {
    await batch((b) {
      b.insertAll(
        bookPassages,
        [
          for (final c in chunks)
            BookPassagesCompanion.insert(
              bookId: bookId,
              chapterIndex: c.chapterIndex,
              charOffset: c.charOffset,
              charLength: c.charLength,
              contentText: c.contentText,
              tokenEstimate: c.tokenEstimate,
            ),
        ],
      );
    });
  }

  /// Atomically replace all chunks for [bookId]: delete existing rows, then
  /// insert [chunks]. Single transaction — readers never see a half-state.
  Future<void> replaceForBook(String bookId, List<PassageChunk> chunks) async {
    await transaction(() async {
      await (delete(bookPassages)..where((t) => t.bookId.equals(bookId))).go();
      await insertMany(bookId, chunks);
    });
  }

  /// Substring search on `content_text`, scoped to [bookId], newest first,
  /// capped at [limit] rows. Empty [query] returns `[]`.
  ///
  /// Substring LIKE is used instead of FTS5 MATCH because the default
  /// unicode61 tokenizer treats CJK text as single tokens — substring
  /// queries like "活着" would never match "人是为了活着本身而活着" under

  Future<int> deleteForBook(String bookId) {
    return (delete(bookPassages)..where((t) => t.bookId.equals(bookId))).go();
```

```dart

/// Pure-function chapter chunker used by [BookPreprocessor] (T5) Phase 1.
///
/// Strategy:
/// 1. Compute token estimate of the entire chapter via
///    [TokenTruncator.estimateTokens].
/// 2. If <= [_chapterTokenLimit] (100K): one chunk covers the whole text.
///    The chapter fits within LLM context windows comfortably; no slicing.
/// 3. If > 100K: split on `\n\n` boundaries, accumulating paragraphs into
///    slices of ~[_sliceTargetTokens] (500). Final tail <100 tokens merges
///    into the previous slice to avoid tiny tail chunks.
///
/// Returns `[]` for empty / whitespace-only input.
class BookChunker {
  const BookChunker._();

  /// Chapter-level cutoff. Chapters above this token count get sliced.
  static const int chapterTokenLimit = 100000;

  /// Slice target size (tokens) when slicing is needed. Picked to fit
  /// comfortably within DeepSeek's context window after prompt overhead.
  static const int sliceTargetTokens = 500;

  /// Tail-merge threshold: a final slice smaller than this merges into the
  /// previous one. Avoids 1-paragraph stragglers.
  static const int _tailMergeThreshold = 100;

  /// Split [chapterText] into one or more [PassageChunk]s for [chapterIndex].
  static List<PassageChunk> chunk(String chapterText, int chapterIndex) {
    final trimmed = chapterText.trim();
    if (trimmed.isEmpty) return const [];

    final full = chapterText; // preserve original offsets
    final totalTokens = TokenTruncator.estimateTokens(full);
    if (totalTokens <= chapterTokenLimit) {
      return [
        PassageChunk(
          chapterIndex: chapterIndex,
          charOffset: 0,
          charLength: full.length,
          contentText: full,
          tokenEstimate: totalTokens,
        ),
      ];
    }

    // Long chapter: slice on \n\n boundaries.
    final paragraphs = full.split('\n\n');
    final slices = <_Slice>[];
    var current = _Slice();
    for (final p in paragraphs) {
      // +2 for the \n\n separator we'll insert when joining
      final piece = current.isEmpty ? p : '\n\n$p';
      final pieceTokens = TokenTruncator.estimateTokens(piece);
      if (current.tokens + pieceTokens > sliceTargetTokens && !current.isEmpty) {
        slices.add(current);
        current = _Slice()..append(p, p.length, TokenTruncator.estimateTokens(p));
      } else {
        current.append(piece, piece.length, pieceTokens);
      }
    }
    if (!current.isEmpty) slices.add(current);

    // Tail merge: if last slice is tiny, fold into previous.
    if (slices.length >= 2 &&
        slices.last.tokens < _tailMergeThreshold) {
      final last = slices.removeLast();
      slices.last.absorb(last);
    }

    // Convert to PassageChunk with absolute offsets.
    final result = <PassageChunk>[];
    var offset = 0;
    for (final s in slices) {
      result.add(PassageChunk(
        chapterIndex: chapterIndex,
        charOffset: offset,
        charLength: s.length,
        contentText: s.text,
        tokenEstimate: s.tokens,
      ));
      offset += s.length;
    }
    return result;
  }
}

class _Slice {
  String text = '';
  int length = 0;
  int tokens = 0;

  bool get isEmpty => tokens == 0;

  void append(String piece, int charLength, int tokenDelta) {
    text += piece;
    length += charLength;
    tokens += tokenDelta;
  }

  void absorb(_Slice other) {
    text += other.text;
    length += other.length;
    tokens += other.tokens;
  }
}
```

```dart
import '../../data/local/daos/book_passages_dao.dart';
import '../../data/models/book.dart';

import 'api_key_store.dart';

/// Terminal errors that abort the whole preprocessing run.
enum PreprocessError {
  authFailed,
  rateLimited,
  circuitBroken,
}

sealed class PreprocessEvent {}

class PreprocessProgressEvent extends PreprocessEvent {
  PreprocessProgressEvent({
    required this.currentChapter,
    required this.totalChapters,
    required this.phase,
  });
  final int currentChapter;
  final int totalChapters;
  final PreprocessPhase phase; // chunking | summarizing
}

enum PreprocessPhase { chunking, summarizing }

class PreprocessChapterFailedEvent extends PreprocessEvent {
  PreprocessChapterFailedEvent(this.chapterIndex, this.error);
  final int chapterIndex;
  final Object error;
}

class PreprocessDoneEvent extends PreprocessEvent {
  PreprocessDoneEvent(this.failedChapters);
  final List<int> failedChapters;
}

class PreprocessErrorEvent extends PreprocessEvent {
  PreprocessErrorEvent(this.error);
  final PreprocessError error;
}

/// Orchestrates the 2-phase batch preprocessing for a [Book].
///
/// Phase 1 (chunking): synchronous, fast. For each chapter, fetch text via
/// [ChapterTextProvider], chunk via [BookChunker], persist via
/// [BookPassagesDao.insertMany].
///
/// Phase 2 (summarizing): asynchronous, calls LLM via [AiGuide] in
/// chapter mode. Skips chapters already cached in ai_summaries (the AiGuide
/// cache lookup handles this). Throttled at [throttleDelay] between chapters
/// to avoid rate limiting.
///
/// Circuit breaker: 3 consecutive chapter failures abort Phase 2 with
/// `circuitBroken`. Failures reset on any success.
///
/// skipIfRunning: a second [start] for the same book returns the in-flight
/// stream rather than starting a duplicate run.
class BookPreprocessor {
  BookPreprocessor({
    required this.passagesDao,
    required this.chapterTextProviderFor,
    required this.aiGuide,
    required this.apiKeys,
    required this.chapterCountFor,
    this.throttleDelay = const Duration(seconds: 2),
  });

  final BookPassagesDao passagesDao;
  final ChapterTextProvider Function(Book) chapterTextProviderFor;
  final AiGuide aiGuide;
  final ApiKeyStoreLike apiKeys;
  /// Returns the total chapter count for [Book]. Injected so tests don't
  /// need to read EPUB files; production wires this to engine.toc.length.
  final Future<int> Function(Book) chapterCountFor;
  final Duration throttleDelay;

  final StreamController<PreprocessEvent> _controller =
      StreamController<PreprocessEvent>.broadcast();
  bool _cancelled = false;
  bool _running = false;

  /// Start preprocessing [book]. If a run for this book is already active,
  /// returns the existing stream (skipIfRunning).
  Stream<PreprocessEvent> start(Book book) {
    if (_running) return _controller.stream;
    _running = true;
    _cancelled = false;
    _run(book);
    return _controller.stream;
  }

  /// Cooperative cancel. The current phase finishes its in-flight chapter
  /// then stops. Already-persisted chunks/summaries remain.
  void cancel() {
    _cancelled = true;
  }

  Future<void> _run(Book book) async {
    try {
      final total = await chapterCountFor(book);
      await _phase1Chunk(book, total);
      if (_cancelled) {
        await _controller.close();
        return;
      }
      await _phase2Summarize(book, total);
      if (!_controller.isClosed) {
        _controller.add(PreprocessDoneEvent(const []));
      }
    } finally {
      _running = false;
      if (!_controller.isClosed) await _controller.close();
    }
  }

  Future<void> _phase1Chunk(Book book, int total) async {
    final provider = chapterTextProviderFor(book);
    for (var i = 0; i < total; i++) {
      if (_cancelled) return;
      final text = await provider.get(book.filePath, i);
      _controller.add(PreprocessProgressEvent(
        currentChapter: i + 1,
        totalChapters: total,
        phase: PreprocessPhase.chunking,
      ));
      if (text == null || text.trim().isEmpty) continue;
      final chunks = BookChunker.chunk(text, i);
      if (chunks.isNotEmpty) {
        await passagesDao.insertMany(book.id, chunks);
      }
    }
  }

  Future<void> _phase2Summarize(Book book, int total) async {
    final creds = await apiKeys.load();
    if (creds == null) return; // No key: chunking still useful, skip Phase 2
    final provider = chapterTextProviderFor(book);
    var consecutiveFailures = 0;
    final failed = <int>[];

    for (var i = 0; i < total; i++) {
      if (_cancelled) return;

      _controller.add(PreprocessProgressEvent(
        currentChapter: i + 1,
        totalChapters: total,
        phase: PreprocessPhase.summarizing,
      ));

      // Skip empty chapters (no chunking output → nothing to summarize)
      final text = await provider.get(book.filePath, i);
      if (text == null || text.trim().isEmpty) continue;

      final title = await provider.title(book.filePath, i);
      try {
        final done = Completer<void>();
        AiGuideError? termErr;
        final sub = aiGuide
            .run(
              book: book,
              mode: AiGuideMode.chapter,
              chapterIndex: i,
              chapterTitle: title,
            )
            .listen(
              (event) {
                if (event is AiErrorEvent) {
                  termErr = event.error;
                  if (!done.isCompleted) done.complete();
                }
              },
              onDone: () {
                if (!done.isCompleted) done.complete();
              },
              onError: (Object e) {
                termErr = AiGuideError.serverError;
                if (!done.isCompleted) done.completeError(e);
              },
              cancelOnError: true,
            );
        await done.future;
        await sub.cancel();

        if (termErr != null) {
          switch (termErr!) {
            case AiGuideError.authFailed:
              _controller.add(
                  PreprocessErrorEvent(PreprocessError.authFailed));
              _controller.close();
              return;
            case AiGuideError.rateLimited:
              _controller.add(
                  PreprocessErrorEvent(PreprocessError.rateLimited));
              _controller.close();
              return;
            case AiGuideError.network:
            case AiGuideError.serverError:
            case AiGuideError.parseError:
            case AiGuideError.emptySource:
            case AiGuideError.cancelled:
              consecutiveFailures += 1;
              failed.add(i);
              if (consecutiveFailures >= 3) {
                _controller.add(PreprocessErrorEvent(
                    PreprocessError.circuitBroken));
                _controller.close();
                return;
              }
              continue;
            case AiGuideError.noApiKey:
              return; // Treated as soft stop
          }
        } else {
          consecutiveFailures = 0;
        }
      } catch (e) {
        consecutiveFailures += 1;
        failed.add(i);
        _controller.add(PreprocessChapterFailedEvent(i, e));
        if (consecutiveFailures >= 3) {
          _controller.add(
              PreprocessErrorEvent(PreprocessError.circuitBroken));
          _controller.close();
          return;
        }
      }

      if (i < total - 1 && !_cancelled) {
        await Future.delayed(throttleDelay);
      }
    }
  }
}
```

```dart
/// Test-friendly interface so [BookPreprocessController] can be constructed

abstract class BookPreprocessorLike {
  Stream<PreprocessEvent> start(Book book);
  void cancel();

/// Riverpod controller that converts the [BookPreprocessor]'s event stream
/// into a reactive [PreprocessState] for the UI.
class BookPreprocessController extends StateNotifier<PreprocessState> {
  BookPreprocessController(this._preprocessor)
      : super(const PreprocessState());

  final BookPreprocessorLike _preprocessor;
  StreamSubscription<PreprocessEvent>? _sub;

  void start(Book book) {
    _sub?.cancel();
    state = const PreprocessState(status: PreprocessStatus.chunking);
    _sub = _preprocessor.start(book).listen(
      _onEvent,
      onError: (Object e) {
        state = state.copyWith(
          status: PreprocessStatus.error,
          error: PreprocessError.circuitBroken,
        );
      },
      onDone: () {
        if (state.status != PreprocessStatus.error &&
            state.status != PreprocessStatus.done) {
          state = state.copyWith(status: PreprocessStatus.done);
        }
      },
      cancelOnError: true,
    );
  }

  void cancel() => _preprocessor.cancel();

  void _onEvent(PreprocessEvent event) {
    switch (event) {
      case PreprocessProgressEvent(
        :final currentChapter,
        :final totalChapters,
        :final phase
      ):
        state = state.copyWith(
          status: phase == PreprocessPhase.chunking
              ? PreprocessStatus.chunking
              : PreprocessStatus.summarizing,
          currentChapter: currentChapter,
          totalChapters: totalChapters,
        );
      case PreprocessChapterFailedEvent():
        // Counted in failedChapters via DoneEvent; no state change here to
        // avoid thrash.
        break;
      case PreprocessDoneEvent(:final failedChapters):
        state = state.copyWith(
          status: PreprocessStatus.done,
          failedChapters: failedChapters,
          clearError: true,
        );
      case PreprocessErrorEvent(:final error):
        state = state.copyWith(
          status: PreprocessStatus.error,
          error: error,
        );
    }
  }

  @override
  void dispose() {
    _sub?.cancel();
    super.dispose();
  }
}
```

```dart
/// Parses `[ch=N]` markers in LLM Q&A answers into ordered [TextSegment]s.
/// Plain text between/around markers becomes [PlainSegment]s; each marker
/// becomes a [CitationSegment] preserving its original `[ch=N]` text.
class QaCitationParser {
  const QaCitationParser._();

  static final RegExp _pattern = RegExp(r'\[ch=(\d+)\]');

  /// Split [llmOutput] into ordered [TextSegment]s. Invalid markers (e.g.
  /// `[ch=abc]`) are not matched and remain in the surrounding PlainSegment.
  static List<TextSegment> parse(String llmOutput) {
    if (llmOutput.isEmpty) return const [];
    final result = <TextSegment>[];
    var lastEnd = 0;
    for (final match in _pattern.allMatches(llmOutput)) {
      if (match.start > lastEnd) {
        result.add(PlainSegment(llmOutput.substring(lastEnd, match.start)));
      }
      final n = int.parse(match.group(1)!);
      result.add(CitationSegment(n, match.group(0)!));
      lastEnd = match.end;
    }
    if (lastEnd < llmOutput.length) {
      result.add(PlainSegment(llmOutput.substring(lastEnd)));
    }
    return result;
  }

  /// Convenience: just the chapter indices, in order, deduped.
  static List<int> extractCitations(String llmOutput) {
    final seen = <int>{};
    final result = <int>[];
    for (final match in _pattern.allMatches(llmOutput)) {
      final n = int.parse(match.group(1)!);
      if (seen.add(n)) result.add(n);
    }
    return result;
  }
}
```

```dart
enum QaError {
  noApiKey,
  emptyIndex,
  authFailed,
  rateLimited,
  network,
  serverError,
  parseError,
}

sealed class QaEvent {}

class QaChunkEvent extends QaEvent {
  QaChunkEvent(this.chunk);
  final String chunk;
}

class QaCompleteEvent extends QaEvent {
  QaCompleteEvent({
    required this.answer,
    required this.citations,
    required this.fromHistory,
  });
  final String answer;
  final List<int> citations;
  final bool fromHistory;
}

class QaErrorEvent extends QaEvent {
  QaErrorEvent(this.error);
  final QaError error;
}

/// Test-friendly interface for the LLM streaming client. Production wires
/// this to [OpenAiCompatibleClient].
abstract class QaClientLike {
  Stream<String> streamChat({required String prompt});
}

/// Same-bench orchestrator for Q&A: history short-circuit → FTS retrieval →
/// prompt → stream → parse → persist.
class BookQaService {
  BookQaService({
    required this.apiKeys,
    required this.passagesDao,
    required this.qaHistoryDao,
    required this.clientFactory,
    this.retryDelays = const [
      Duration(seconds: 1),
      Duration(seconds: 2),
      Duration(seconds: 4),
    ],
    this.limit = 5,
  });

  final ApiKeyStoreLike apiKeys;
  final BookPassagesDao passagesDao;
  final QaHistoryDao qaHistoryDao;
  final QaClientLike Function(ApiKeyCredentials) clientFactory;
  final List<Duration> retryDelays;
  final int limit;

  Stream<QaEvent> ask({
    required Book book,
    required String question,
  }) async* {
    // 1. History short-circuit
    final cached =
        await qaHistoryDao.findSameQuestion(book.id, question);
    if (cached != null) {
      yield QaCompleteEvent(
        answer: cached.answer,
        citations: cached.citations,
        fromHistory: true,
      );
      return;
    }

    // 2. API key check
    final creds = await apiKeys.load();
    if (creds == null) {
      yield QaErrorEvent(QaError.noApiKey);
      return;
    }

    // 3. Retrieve top-K chunks
    final chunks = await passagesDao.searchFts(question, book.id, limit: limit);
    if (chunks.isEmpty) {
      yield QaErrorEvent(QaError.emptyIndex);
      return;
    }

    // 4. Build prompt with [ch=N] markers
    final passageChunks = chunks
        .map((p) => PassageChunk(
              chapterIndex: p.chapterIndex,
              charOffset: p.charOffset,
              charLength: p.charLength,
              contentText: p.contentText,
              tokenEstimate: p.tokenEstimate,
            ))
        .toList(growable: false);
    final prompt = PromptBuilder.qa(question, passageChunks);

    // 5. Stream with retry
    final accumulated = StringBuffer();
    var attempt = 0;
    while (true) {
      try {
        await for (final chunk
            in clientFactory(creds).streamChat(prompt: prompt)) {
          accumulated.write(chunk);
          yield QaChunkEvent(chunk);
        }
        // Stream completed — persist + emit complete
        final answer = accumulated.toString();
        final citations = QaCitationParser.extractCitations(answer);
        try {
          await qaHistoryDao.insert(
            bookId: book.id,
            question: question,
            answer: answer,
            citations: citations,
          );
        } catch (_) {
          // Swallow persistence errors — answer is still returned to UI.
        }
        yield QaCompleteEvent(
          answer: answer,
          citations: citations,
          fromHistory: false,
        );
        return;
      } on AiNetworkException {
        if (attempt >= retryDelays.length - 1) {
          yield QaErrorEvent(QaError.network);
          return;
        }
        await Future.delayed(retryDelays[attempt]);
        attempt += 1;
        continue;
      } on AiAuthException {
        yield QaErrorEvent(QaError.authFailed);
        return;
      } on AiRateLimitException {
        yield QaErrorEvent(QaError.rateLimited);
        return;
      } on AiServerException {
        yield QaErrorEvent(QaError.serverError);
        return;
      } on AiParseException {
        yield QaErrorEvent(QaError.parseError);
        return;
      }
    }
  }
}
```

```dart
enum QaStatus { idle, loading, streaming, done, error }

class QaState {
  const QaState({
    this.status = QaStatus.idle,
    this.answer = '',
    this.citations = const [],
    this.error,
    this.fromHistory = false,
    this.history = const [],
  });

  final QaStatus status;
  final String answer;
  final List<int> citations;
  final QaError? error;
  final bool fromHistory;
  final List<QaHistoryEntry> history;

  QaState copyWith({
    QaStatus? status,
    String? answer,
    List<int>? citations,
    QaError? error,
    bool? fromHistory,
    List<QaHistoryEntry>? history,
    bool clearError = false,
  }) {
    return QaState(
      status: status ?? this.status,
      answer: answer ?? this.answer,
      citations: citations ?? this.citations,
      error: clearError ? null : (error ?? this.error),
      fromHistory: fromHistory ?? this.fromHistory,
      history: history ?? this.history,
    );
  }

/// Test-friendly interface so [QaController] can be constructed with a
/// fake stream in tests.
abstract class BookQaServiceLike {
  Stream<QaEvent> ask({required Book book, required String question});
}

class QaController extends StateNotifier<QaState> {
  QaController(this._service) : super(const QaState());

  final BookQaServiceLike _service;
  StreamSubscription<QaEvent>? _sub;

  void ask({required Book book, required String question}) {
    _sub?.cancel();
    state = const QaState(status: QaStatus.loading);
    _sub = _service.ask(book: book, question: question).listen(
      _onEvent,
      onError: (Object e) {
        state = state.copyWith(
            status: QaStatus.error, error: QaError.serverError);
      },
      onDone: () {
        if (state.status != QaStatus.error &&
            state.status != QaStatus.done) {
          state = state.copyWith(status: QaStatus.done);
        }
      },
      cancelOnError: true,
    );
  }

  void reset() {
    _sub?.cancel();
    _sub = null;
    state = const QaState();
  }

  void setHistory(List<QaHistoryEntry> entries) {
    state = state.copyWith(history: entries);
  }

  void _onEvent(QaEvent event) {
    switch (event) {
      case QaChunkEvent(:final chunk):
        state = state.copyWith(
          status: QaStatus.streaming,
          answer: state.answer + chunk,
        );
      case QaCompleteEvent(:final answer, :final citations, :final fromHistory):
        state = state.copyWith(
          status: QaStatus.done,
          answer: answer,
          citations: citations,
          fromHistory: fromHistory,
          clearError: true,
        );
      case QaErrorEvent(:final error):
        state = state.copyWith(status: QaStatus.error, error: error);
    }
  }

  @override
  void dispose() {
    _sub?.cancel();
    super.dispose();
  }
}
```

```dart
import 'package:flutter/material.dart';

import '../../../services/ai/qa_citation_parser.dart';

/// Convert [segments] into a list of [InlineSpan]s for use in
/// [RichText] or [Text.rich]. [PlainSegment]s become plain [TextSpan]s
/// with [plainStyle]; [CitationSegment]s become [TextSpan]s with
/// [citationStyle] and a [TapGestureRecognizer] that calls
/// [onCitationTap] with the cited chapter index.
///
/// Callers must dispose gesture recognizers when the widget is unmounted
/// — wrap [RichText] in a [StatefulWidget] and dispose in [dispose], or
/// use [Text.rich] inside a builder that recreates the spans each build
/// (the recognizers leak per build only if the underlying framework caches
/// them, which it doesn't for Text.rich).
List<InlineSpan> buildQaCitationSpans(
  List<TextSegment> segments, {
  required void Function(int chapterIndex) onCitationTap,
  required TextStyle plainStyle,
  required TextStyle citationStyle,
}) {
  return [
    for (final s in segments)
      switch (s) {
        PlainSegment(:final text) => TextSpan(text: text, style: plainStyle),
        CitationSegment(:final chapterIndex, :final marker) => TextSpan(
            text: marker,
            style: citationStyle,
            recognizer: TapGestureRecognizer()
              ..onTap = () => onCitationTap(chapterIndex),
          ),
      },
  ];
}
```
