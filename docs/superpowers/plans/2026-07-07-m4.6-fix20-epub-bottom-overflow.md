## Architecture

### 当前（broken）

```
_buildPaged:
  cache miss → RenderedHtmlMeasurer (每段独立 HtmlWidget 测高)
            → paginateFromActualHeights (累加每段高度算 breaks)
            → 每页 HTML 喂 HtmlWidget 渲染
  问题：单段测量 ≠ 整页渲染（drift -47px / 58%）
```

### 新（A1）

```
_buildPaged:
  cache miss → PageConvergenceMeasurer (新)
              1. 用 TextPainter 估算初始 breaks
              2. 对每页 HTML 整体 HtmlWidget 测高
              3. 超 slot → 末段推下页；不足 → 下页首段拉过来
              4. 迭代到稳定（≤ 5 轮）
            → 返回收敛后的 breaks（直接用于渲染，无需 paginateFromActualHeights）
  cache hit → 直接用上轮收敛的 breaks
```

**关键变化**：measurer 不再返回「每段高度」，而是直接返回「收敛后的 PageBreak 列表」。paginator.paginateFromActualHeights 不再被调用（保留函数不删，标记 deprecated）。

## Task 1：新建 PageConvergenceMeasurer（核心）

**Files**：`reader_engine_epub_view/lib/page_convergence_measurer.dart`（新建）

**Background**：spec A1。整页一次测量 + 二分式迭代收敛。

**Steps**：
- [ ] 定义 widget：`PageConvergenceMeasurer`，输入 chapterHtml + viewport + typography + margin + onConverged
- [ ] initState：用 Paginator.paginateWithText（TextPainter 估算）算初始 breaks
- [ ] build：Offstage + 每页 HTML 各包一个 HtmlWidget（key=GlobalKey），等待 layout
- [ ] post-frame：遍历每页 GlobalKey 拿 RenderBox.size.height，对比 slot（viewport.height - 2*margin）
  - 若 page[i].height > slot：把 breaks[i].endOffset 回退到倒数第二段 start，breaks[i+1] 起 start 同步
  - 若 page[i].height < slot - lineHeight 且 page[i+1] 首段高度 < 余量：breaks[i].endOffset 推进到下一段 start
- [ ] 若 breaks 变化 → setState 触发 rebuild，重新 layout → 下一轮测量
- [ ] 若 breaks 不变 或 迭代轮数 ≥ 5 → onConverged(breaks)
- [ ] 兜底：含 `<img>` 的页等额外 2 帧（缓解 R3 图片异步）

**Verification**：
- [ ] 单元测试：给定已知 HTML，收敛后每页 ≤ slot
- [ ] 单元测试：迭代上限兜底（极端 HTML 不死循环）

**Background**：cache miss 时挂 PageConvergenceMeasurer 替代 RenderedHtmlMeasurer。cache hit 直接用 `_convergedBreaks`。

**Steps**：
- [ ] 新增字段 `List<PageBreak>? _convergedBreaks`（替代 `_measuredHeights` 的角色）
- [ ] `_buildPaged` cache miss 分支：先用 TextPainter 估 breaks 渲染 PageView（保持单阶段，无空白帧），同时挂 offstage PageConvergenceMeasurer

- [ ] 保留 `_measurementKey` 指纹缓存机制（参数变就重测）
- [ ] 移除 RenderedHtmlMeasurer 调用点（widget 本身保留不删）
