### 3.4 FontImportService

```dart
sealed class FontImportResult {
  const FontImportResult();
}
class FontImportCancelled extends FontImportResult {}
class FontImportAlreadyExists extends FontImportResult {
  final UserFont existing;
  const FontImportAlreadyExists(this.existing);
}
class FontImportInvalid extends FontImportResult {
  final String reason;
  const FontImportInvalid(this.reason);
}
class FontImportReadError extends FontImportResult {
  final String message;
  const FontImportReadError(this.message);
}
class FontImportSuccess extends FontImportResult {
  final UserFont font;
  const FontImportSuccess(this.font);
}

class FontImportService {
  FontImportService(this._fontsRepo, this._appDocsPath);

  final FontsRepository _fontsRepo;
  final String _appDocsPath;

  Future<FontImportResult> importFont() async {
    // 1. file_picker pickFiles
    final result = await FilePicker.platform.pickFiles(
      type: FileType.custom,
      allowedExtensions: const ['ttf', 'otf', 'TTF', 'OTF'],
    );
    if (result == null || result.files.isEmpty) {
      return const FontImportCancelled();
    }
    final picked = result.files.single;
    final bytes = await _readBytes(picked);  // try/catch → FontImportReadError

    // 2. SHA-1 dedup
    final hash = sha1.convert(bytes).toString();
    final existing = await _fontsRepo.findByHash(hash);
    if (existing != null) return FontImportAlreadyExists(existing);

    // 3. Copy to fonts/ subdir
    final safeName = _sanitize(picked.name);
    final stamp = DateTime.now().microsecondsSinceEpoch;
    final destPath = p.join(_appDocsPath, 'fonts', '${stamp}_$safeName');
    await File(destPath).parent.create(recursive: true);
    await File(destPath).writeAsBytes(bytes);

    // 4. FontLoader validate
    final familyName = p.basenameWithoutExtension(destPath); // MVP: 文件名 stem
    final loader = FontLoader(familyName)..addFont(FileAsset(path: destPath));
    try {
      await loader.load();
    } catch (e) {
      await File(destPath).delete(); // 回滚
      return FontImportInvalid('FontLoader.load failed: $e');
    }

    // 5. Insert DB row
    final font = UserFont(
      id: uuid(),
      displayName: familyName,
      fileName: p.basename(destPath),
      familyName: familyName,
      hashSha1: hash,
      absolutePath: destPath,
      addedAt: DateTime.now(),
    );
    await _fontsRepo.insert(font);
    return FontImportSuccess(font);
  }

  Future<void> deleteFont(String fontId, {TypoProfileRepository? profileRepo}) async {
    final font = await _fontsRepo.getById(fontId);
    if (font == null) return;
    // 约束：被 profile 引用则阻止删除（参见 §4.3）
    if (profileRepo != null) {
      final referencing = await profileRepo.findProfilesReferencingFont(font.familyName);
      if (referencing.isNotEmpty) {
        throw FontInUseException(referencing);
      }
    }
    await _fontsRepo.delete(fontId);
    try {
      await File(font.absolutePath).delete();
    } catch (_) {
      // Best-effort: DB row 已删，文件不存在不致命
    }
  }
}
```

## 4. Error Handling

### 4.1 字体导入失败矩阵

| 失败模式 | 检测点 | 用户反馈 | 系统状态 |
|---|---|---|---|
| 用户取消 file_picker | `pickFiles() returns null` | 静默返回 | 无副作用 |
| 文件不可读（权限/IO） | `readAsBytes` throws | SnackBar `读取文件失败：${e}` | 无副作用 |
| SHA-1 命中已有字体 | DB 查询返回 row | SnackBar `字体已存在：${existing.displayName}` | 无副作用 |
| 复制失败（磁盘满/路径） | `File.copy`/`writeAsBytes` throws | SnackBar `保存文件失败：${e}` | 无副作用 |
| 字体无效/损坏 | `await loader.load()` throws | SnackBar `字体文件无效` | 自动删已复制文件，fonts/ 目录干净 |
| familyName 提取失败 | MVP 不解析 TTF name table | 用文件名 stem 作 familyName | 用户可在列表里重命名 |

**关键约束：** FontLoader.load 是验证的金标准。user_fonts 表 row 必须在 FontLoader.load 成功**之后**才插入，避免出现"DB 有记录但字体实际无法渲染"的脏数据。

### 4.2 Profile 操作约束

| 操作 | 约束 | 处理 |
|---|---|---|
| 删除最后一个 profile | 防止 0 profile 状态 | 阻止删除，SnackBar `至少保留一个预设` |
| 删除当前默认 profile | 防止"无默认" | 阻止删除，SnackBar `请先切换其他预设为默认` |
| 删除当前 reader 正在用的 profile | reader 引用悬空 | M3.5 简化：reader 用 profile **副本**（settings 字段），删除 profile 不影响正在打开的 reader；下次打开 reader 用新默认 |
| 重命名为空字符串 | UI 验证 | Dialog 输入框 validator：`value.isEmpty ? '请输入名称' : null` |
| 重命名为重复名称 | 允许 | DB 层 name 不唯一；UI 层不阻拦 |

### 4.3 字体删除约束

| 操作 | 约束 | 处理 |
|---|---|---|
| 删除字体被某 profile 引用 | profile.settings.fontFamily 匹配 | 阻止删除，SnackBar `预设 "${profileName}" 正在使用此字体，请先切换`。抛 `FontInUseException` 由 UI 层 catch |
| 删除字体被 reader 正在用 | engine.typography.fontFamily 匹配 | M3.5 简化：允许删除，reader 继续用 FontLoader 缓存直到重启；SnackBar 提示 `已删除，重启后完全移除` |
| 字体文件已被外部删除 | File.delete throws | catch + 静默，DB row 仍删除（DB 是 source of truth） |

### 4.4 Locale / ThemeMode 异常

- `Locale('zh')` / `Locale('en')` 是 Material 内置 supported locale，无解析失败风险
- 持久化值是 enum 字符串（'system'/'chinese'/'english'），反序列化失败回退到 `system`
- ThemeMode 同理：'system'/'light'/'dark'，失败回退 `system`

### 4.5 i18n key 缺失

- `gen-l10n` 在编译时检查 arb key 一致性（zh 和 en 必须对齐），CI 跑 `flutter gen-l10n` 防漏翻译
- 运行时 `AppLocalizations.of(context)` 不会返回 null（MaterialApp 配置 delegates）
- 未知 fallback：不做；gen-l10n 编译时保证

### 4.6 BookCell 溢出菜单

- 删除操作走通用 `showConfirmDialog`（M3.5 新建），Undo SnackBar 5s 内可恢复（`bookRepository.undoDelete` 或简单 cache + re-insert）
- 删除书会级联删 notes/progress（DB schema ON DELETE CASCADE），不需要 app 层额外处理
- 删除进行中 cell 显示 CircularProgressIndicator（防双击）

### 4.7 NotesPage 真实 Book 元数据

- `BookRepository.getBookById` 可能返回 null（书刚被删但 NotesPage 还在栈里）
- null → AppBar 显示 "笔记"（无书名），导出按钮 disable，body 显示 `书不存在或已删除` + 返回按钮
- 删除 `_stubBookForExport`，直接用真实 Book；如果 Book 为 null，禁用导出

## 7. 风险与缓解

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| FontLoader.load 在 Windows 上行为与 Linux test 环境不一致 | 低 | 中 | 测试 fixture 用最小可用 .ttf；CI 上跑 widget test 间接验证 |
| arb 文件维护成本（150-200 key） | 中 | 中 | gen-l10n 强制 zh/en 对齐；缺 key 编译报错 |
| inline 编辑 ProfileTile 复杂度溢出 | 中 | 中 | 若 widget 测试发现状态过多，pivot 为单独 route |
| 删除字体级联检查（profile 引用）N+1 查询 | 低 | 低 | 单次 query 拿所有 profile settings JSON 反序列化遍历；profile 量很小 |
| M3.5 范围溢出（i18n 全量比预期大） | 中 | 中 | 若 i18n 估算 >2 天，分两次：先 framework + nav label，后剩余 key |
| `gen-l10n` 在中文路径下的兼容性 | 中 | 高 | M3.5 T0 优先验证；如失败回退手写 AppLocalizations 类（替代 gen-l10n） |
