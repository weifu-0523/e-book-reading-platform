- 书库列表 UI（grid + list 双视图，默认 grid）

**不包含**（明确推迟）：

### 2.2 关键决策

| 项 | 决策 | 理由 |
|---|---|---|
| 状态类风格 | 手写 immutable class（`@immutable` + `==` / `hashCode`） | 与 M1/M2 一致（`Annotation` / `BookNote`），避免引入 freezed 风格分裂 |
| 路由 | go_router（替换 M2 的 `onGenerateRoute`） | 已发布依赖，M3 多页面路由必需；M2 单 reader 路由是简化决策，现在清除技术债 |
| Cover 提取时机 | 导入时同步解析 + 写 PNG | 首次打开列表即有封面；失败静默降级占位图，不阻塞导入 |
| Cover 存储 | `{appDocDir}/covers/{bookId}.png` | `FileStorage.storeCover()` 已就绪 |
| Tags 存储模型 | 独立 `book_tags` 表（bookId × tag 多对多） | 跨书按 tag 筛选 = JOIN，比 JSON 列高效；schema v2 迁移 |
| 手动排序 | `Books.sortOrder: integer nullable` 列 | 拖拽只更新该列；null = 不参与手动，按默认排序 |
| 视图模式持久化 | `SettingsRepository` 键值对（key: `library.viewMode`） | 简单，无需新表 |
| 搜索范围 | 仅书名 / 作者 / tag | 跨表搜笔记内容在 M3.4 统一做 |
| 排版补全粒度 | 行距 3 档 / 字体族 3 档（系统/衬线/无衬线）/ 页边距 3 档 | 与设计文档 §3.4 一致；字体文件 bundle 推迟到 M3.5 |
| 排版补全工作量 | 仅 UI 暴露 + 接线，**模型层与持久化层已就绪** | `TypographySettings` 已含 lineHeight/fontFamily/pageMargin 字段；`TypographyDao` 走 JSON 持久化；`typography_css.dart` 已经把 lineHeight/fontFamily 应用到 TextStyle；只需在 M2 TypographyPanel 加 3 个控件 + 写入持久化层 |

## 3. 数据模型增量

### 3.1 新增 `book_tags` 表

```dart
// app/lib/data/local/tables/book_tags.dart
import 'package:drift/drift.dart';

class BookTags extends Table {
  TextColumn get bookId => text()
      .customConstraint('REFERENCES books(id) ON DELETE CASCADE')();
  TextColumn get tag => text()();

  @override
  Set<Column> get primaryKey => {bookId, tag};
}
```

设计要点：
- 复合主键 (bookId, tag) 防重复
- ON DELETE CASCADE：删书自动删 tag 关联，无需手动级联
- tag 文本自由格式，不做归一化（MVP 阶段够用；查询压力上来再考虑独立 tags 表）

### 3.2 修改 `Books` 表（schema v2）

```dart
// 新增列
IntColumn get sortOrder => integer().nullable()();  // null = 不参与手动排序
```

迁移策略（**v2 → v3**；M1 已经在 v2 加了 file_hash 唯一索引）：
- `ALTER TABLE books ADD COLUMN sort_order INTEGER;`（drift 自动生成）
- `CREATE TABLE book_tags (...)` + 索引 `idx_book_tags_tag` on (tag)
- `database.dart` 的 `schemaVersion` 从 2 改为 3，`onUpgrade` 加 `if (from < 3) { ... }` 分支
- 已启用的 `PRAGMA foreign_keys = ON`（database.dart:66）保证 `ON DELETE CASCADE` 生效
- 写 migration test 验证：v2 数据库升级后 schema 完整 + 旧数据无丢失

## 5. UX 流程

### 5.1 流程 1：导入新书

```
[LibraryPage AppBar「+」按钮]
    ↓
file_picker.pickFiles(type: custom, allowedExtensions: ['epub', 'pdf'])
    ↓
[显示顶部进度条 LinearProgressIndicator]
    ↓
BookImportService.importFile(file, format: detected)
    ├─ 文件 hash 计算
    ├─ DB 查重
    ├─ 复制到 library/{hash}.{ext}
    ├─ 入库
    └─ EpubCoverExtractor.extract() 同步运行（仅 EPUB）
        ├─ epubx parse → 找 meta cover-image href
        ├─ 解压对应 manifest item bytes
        └─ FileStorage.storeCover() → 写 covers/{bookId}.png
            └─ 失败 → 静默降级，coverPath=null
    ↓
[books watchAll stream 自动刷新]
    ↓
[新书出现在列表顶部，按 addedDesc 默认排序]
```

### 5.2 流程 2：长按上下文菜单

```
长按书卡片
    ↓
showModalBottomSheet → ActionSheet 4 项
    ↓
├─ 打开 → context.push('/book/$id')
├─ 查看笔记 → context.push('/book/$id/notes') [M3.3 实现，M3.1 占位 SnackBar "M3.3 解锁"]
├─ 详情 → context.push('/book/$id/details')
└─ 删除 → AlertDialog 确认 → batchDelete([id])
```

### 5.3 流程 3：批量操作

```
长按任意书
    ↓
enterSelectionMode(initialBookId) → mode = selecting
    ↓
[AppBar 切换为 "已选 N 本" + 取消按钮]
[底部 BatchSelectionBar 浮起：删除 / 导出笔记（M3.3 占位）/ 全选]
    ↓
点其他卡片 → toggleSelection(id)
    ↓
点删除 → 确认对话框 → batchDelete()
    ↓

```

### 5.4 流程 4：搜索

```

    ↓

    ↓

```

    ↓

```

    ↓

### 5.7 流程 7：手动排序

```

## 6. 错误处理

| 场景 | 检测 | 处理 |
|---|---|---|
| 导入失败（损坏的 EPUB/PDF） | BookImportService 抛异常 | SnackBar "导入失败：[原因]"；半成品 DB 记录回滚 |
| 导入重复（hash 已存在） | BookImportService 返回 `isNew=false` | SnackBar "已在书库中：[书名]"；不报错 |
| 封面提取失败 | EpubCoverExtractor catch all | 静默降级 `coverPath=null`，UI 显示占位图 |
| 文件路径丢失（用户移动源文件） | `coverLoaderProvider` 或 reader 打开时检测 | 详情页显示警告；reader 失败回 ReaderErrorView |
| 删除单本失败 | `bookRepository.delete` 抛异常 | SnackBar "删除失败"；回滚 UI |
| 批量删除部分失败 | 事务回滚 | SnackBar "删除失败：[N 本未删除]"；状态恢复 |
| Tag 增删失败 | DAO 抛异常 | SnackBar "操作失败"；状态回滚 |
| 搜索 query 过长 | 输入 > 50 字符 | 客户端截断到 50 字符，不报错 |
| 空状态 | books 列表为空 | EmptyLibraryView + CTA"导入第一本书" |
| 搜索无结果 | 过滤后空 | 显示"无匹配书籍"图标 + 清空筛选按钮 |
| 拖拽排序冲突 | 并发更新 sortOrder | 用 drift 事务序列化；最后写赢，无错误 |

| epubx cover 解析在不同 EPUB 版本（2.0/3.0）上行为差异 | 中 | 中 | 早期用 5 本真实 EPUB 跑通；failures 静默降级占位图 |
| ReorderableGridView 在 Flutter 3.27 无原生支持 | 高 | 中 | 已决定用 `reorderables ^0.6.0` 包；如该包与 Flutter 3.27 不兼容则降级——列表模式才支持手动排序，grid 模式禁用手动排序按钮 |
| go_router 重构引入回归（M2 reader 路由） | 中 | 高 | 路由重构任务先写 reader 路由不回归的 widget test，再重构 |
| Tag 筛选 AND 逻辑 SQL 实现复杂 | 低 | 低 | 不用 SQL，UI 层 List.where 过滤（数据量 MVP 级别 < 1000 本） |
| 排版补全破坏 M2 golden 基线 | 中 | 低 | 排版默认值 = M2 当前值，golden 应稳定；如有差异，更新基线 |
| schema v2 migration 在生产 db 失败 | 低 | 高 | 写 migration test + 在 staging 数据库手动验证 |
