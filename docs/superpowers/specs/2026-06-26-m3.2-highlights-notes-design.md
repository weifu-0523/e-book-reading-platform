### 1.4 已知风险

- **R1**：`flutter_widget_from_html` 的 `HtmlWidget` 与 `SelectableRegion` 兼容性未知。若 HtmlWidget 内部已用 `SelectableText.rich` 或自己实现 selection，则冲突。**Mitigation**：T1 spike 1 天内验证；失败 fallback 改方案 B（webview）或限制为 scroll 模式选区。
- **R2**：plain text offset 反查 HTML 节点边界，在嵌套标签（`<p><b>x</b>y</p>`）下算法边界易错。**Mitigation**：先写 `HtmlHighlightInjector` 作为 pure 函数 + 充分单元测试（含嵌套、自闭合、属性含 `<` 等边界）。
- **R3**：drift 2.18 的 FTS5 触发器写法（`@DependsOn` vs 手写 SQL）需要 spike。**Mitigation**：参考 drift 官方 FTS5 example，T25 完成。
- **R4**：选中文本在章节内多次出现时，offset 反查歧义。**Mitigation**：优先用 `SelectionListener.selection.startPoint.offset`，substring 仅 fallback；fallback 命中首个，log warning。

## 3. 数据模型

### 3.1 `EpubRangeLocator`

```dart
@immutable
class EpubRangeLocator extends Locator {
  final int chapterIndex;
  final String? chapterTitle;
  final int startOffset;  // chapter plainText 字符 offset（含）
  final int endOffset;    // chapter plainText 字符 offset（不含）
  final String quote;     // 选中文本，渲染失败 fallback 用

  const EpubRangeLocator({
    required this.chapterIndex,
    required this.startOffset,
    required this.endOffset,
    required this.quote,
    this.chapterTitle,
  });

  @override
  Map<String, dynamic> toJson() => {
    'type': 'epubRange',
    'chapterIndex': chapterIndex,
    if (chapterTitle != null) 'chapterTitle': chapterTitle,
    'startOffset': startOffset,
    'endOffset': endOffset,
    'quote': quote,
  };

  // fromJson：在 Locator.fromJson switch 增加 case 'epubRange'
  // toJsonString：'$chapterIndex:$startOffset-$endOffset'
  // == / hashCode：覆盖 5 字段
}
```

**Why plain text offset**：
- HTML 内容固定（EPUB 源），plain text 派生固定
- 字体/主题/分页改变 → plain text 不变 → offset 稳定
- 同步到其他设备 → plain text 同 → offset 同
- 比 CFI 简单（无需解析 DOM 树，HtmlWidget 不暴露节点引用）

**quote 冗余存储**：
- 注入失败（HTML 解析异常、offset 反查失败）时降级为文本搜索
- 用户编辑 quote 后渲染无法精确恢复，用 quote 做最后防线

### 3.2 FTS5 表（迁移 v3 → v4）

```sql
-- schema_v4.sql（drift customStatement）
CREATE VIRTUAL TABLE annotations_fts USING fts5(
  quote, note, tags, content='annotations', content_rowid='rowid'
);

-- 同步触发器：INSERT
CREATE TRIGGER annotations_ai AFTER INSERT ON annotations BEGIN
  INSERT INTO annotations_fts(rowid, quote, note, tags)
  VALUES (new.rowid, new.quote, new.note, new.tags);
END;

-- 同步触发器：DELETE
CREATE TRIGGER annotations_ad AFTER DELETE ON annotations BEGIN
  INSERT INTO annotations_fts(annotations_fts, rowid, quote, note, tags)
  VALUES ('delete', old.rowid, old.quote, old.note, old.tags);
END;

-- 同步触发器：UPDATE
CREATE TRIGGER annotations_au AFTER UPDATE ON annotations BEGIN
  INSERT INTO annotations_fts(annotations_fts, rowid, quote, note, tags)
  VALUES ('delete', old.rowid, old.quote, old.note, old.tags);
  INSERT INTO annotations_fts(rowid, quote, note, tags)
  VALUES (new.rowid, new.quote, new.note, new.tags);
END;
```

drift `migration.onUpgrade` from 3 → 4 执行上述 SQL。

### 3.3 数据流：高亮创建

```
1. 用户长按文本 → SelectableRegion 触发选区
2. 用户点工具条 [高亮] → HighlightSelectionControls handleHighlight
3. HighlightSelectionControls 读 SelectableRegion 选区：
   - selectedContent.plainContent（仅选中文本）
   - 在章节 plainText 中 substring 定位（详见 4.3）
4. 弹 HighlightColorPickerDialog → 用户选色
5. 调 NotesController.addHighlight(EpubRangeLocator, color, quote)
6. NotesController：
   a. lazy get-or-create BookNote（如不存在调 createEmptyNote）
   b. 调 repository.addAnnotation(Annotation(...))
   c. 触发 state emit（watchAnnotations 自动重发）
7. EpubxRenderer 监听 notesController 状态 → injectHighlights
8. EpubxRenderer.build() 重新生成 highlightedHtml → 渲染
```

## 4. 选区捕获 + 渲染注入

### 4.1 `PlainTextUtils`

```dart
class PlainTextUtils {
  /// 输入：原始 HTML
  /// 输出：(plainText, htmlOffsetAtPlainIndex)
  ///   - plainText：去除标签后的纯文本
  ///   - htmlOffsetAtPlainIndex[i]：plainText 第 i 个字符在原始 HTML 中的起始 offset
  ///
  /// 算法：扫一遍 HTML，遇 `<` 进入 tag-skip 模式直到 `>`；text 模式累积字符并记录 HTML offset
  static (String, List<int>) htmlToPlainWithOffsets(String html);
}
```

边界：
- 嵌套标签 `<p><b>x</b>y</p>` → plainText = "xy"，offsets = [3, 11]
- 自闭合 `<br/>` → 不贡献字符
- 实体 `&amp;` → 解为 `&`（1 字符，HTML offset 指向 `&`）
- 属性中含 `<` （`<a title="a<b">`）→ 按 tag-skip 处理，可能误判，但 EPUB 罕见，文档化为已知边界

### 4.2 `HtmlHighlightInjector`

```dart
class HtmlHighlightInjector {
  /// 输入：原始 HTML + 当前书本章号命中的 annotations（已按 chapterIndex 过滤）
  /// 输出：注入了 `<span style="background-color: rgba(R,G,B,alpha); border-bottom: ...">` 的 HTML
  ///
  /// 算法：
  /// 1. 调 PlainTextUtils.htmlToPlainWithOffsets 拿 plainText + offsetMap
  /// 2. 对每个 annotation：
  ///    a. 取 (startOffset, endOffset)
  ///    b. 反查 HTML offset：htmlStart = offsetMap[startOffset], htmlEnd = offsetMap[endOffset]
  ///    c. 颜色：HighlightColor → rgba 字符串（如 yellow → rgba(255, 235, 59, 0.4)）
  ///    d. note 非空：加 border-bottom 区分
  ///    e. 插入 `<span style="...">...</span>`
  /// 3. 多个重叠高亮：本 sprint 不支持重叠，重合区按 createdAt 早的优先（log warning）
  static String inject(String html, List<Annotation> annotations);
}
```

颜色映射：

| HighlightColor | RGBA |
|---|---|
| yellow | rgba(255, 235, 59, 0.4) |
| green | rgba(76, 175, 80, 0.4) |
| blue | rgba(33, 150, 243, 0.4) |
| red | rgba(244, 67, 54, 0.4) |
| purple | rgba(156, 39, 176, 0.4) |

### 4.3 选区捕获

```dart
// 在 ReaderPage 的 build 内
SelectableRegion(
  selectionControls: HighlightSelectionControls(
    onHighlight: _onSelectionHighlight,
    onNote: _onSelectionNote,
  ),
  child: EpubxRenderer.build(context),
)

// HighlightSelectionControls
class HighlightSelectionControls extends TextSelectionControls {
  final VoidCallback onHighlight;
  final VoidCallback onNote;
  // override buildToolbar：在原生 toolbar 后追加两个 TextButton
}
```

`onHighlight` / `onNote` 在 ReaderPage 内：
1. 通过 `SelectionListener.maybeOf(context)` 拿 `SelectedContent`
2. `SelectedContent.plainContent` 是**仅选中文本**（Flutter 3.27 API）
3. `SelectableRegion` 内部各 child Selectable 的 offset 是节点局部坐标，跨节点拼接成章节绝对 offset 较复杂
4. **简化方案**：在 EpubxRenderer 暴露的"当前章节 plainText"中搜索 `selectedContent.plainContent`，命中首个即为 startOffset（多次出现 log warning，用户可重选）
5. 反查章节 plainText 由 `PlainTextUtils.htmlToPlainWithOffsets` 提供（与渲染注入同一函数，保证一致）

> **决策**：本 sprint 走简化方案（文本搜索定位）。若用户实测发现定位漂移，M3.3 升级为 offset-based。理由：SelectableRegion API 在 Flutter 3.27 仍 experimental，跨节点 offset 拼接语义不稳定；文本搜索 99% 场景可接受，且 plainText 来源与渲染一致天然避免坐标系错位。

### 4.4 渲染流程

```dart
// EpubxRenderer.build()
@override
Widget build(BuildContext context) {
  final chapters = flatChapters;
  if (chapters.isEmpty) return const SizedBox.shrink();
  final html = chapters[_currentChapterIndex].HtmlContent ?? '';
  final highlightedHtml = _annotationsForChapter.isEmpty
      ? html
      : HtmlHighlightInjector.inject(html, _annotationsForChapter);
  // ... 后续同 M3.1，把 html 换成 highlightedHtml
}

List<Annotation> get _annotationsForChapter =>
    _allAnnotations
        .where((a) =>
            a.locator is EpubRangeLocator &&
            (a.locator as EpubRangeLocator).chapterIndex == _currentChapterIndex)
        .toList();
```

### 7.2 `LocalNotesRepository.watchAnnotations` 实现

```dart
@override
Stream<List<Annotation>> watchAnnotations(String bookId) async* {
  // 通过 bookNoteId 反查
  final noteRow = await _notesDao.getByBookId(bookId);
  if (noteRow == null) {
    yield const [];
    return;
  }
  yield* _annotationsDao.watchByBookNoteId(noteRow.id).map(
      (rows) => rows.map(_toAnnotationModel).toList());
}
```

需要 `AnnotationsDao.watchByBookNoteId(String)` 新方法（drift `select()..where()..watch()`）。

### 7.3 `LocalNotesRepository.searchAnnotations` 实现（FTS5）

```dart
@override
Future<List<Annotation>> searchAnnotations(
  String query, {
  List<String>? tags,
  HighlightColor? color,
}) async {
  // 1. FTS5 MATCH
  final fts = await _annotationsDao.searchFts(_sanitizeFtsQuery(query));
  // 2. 加载完整 Annotation（FTS 只返回 rowid + snippet）
  final annotations = <Annotation>[];
  for (final row in fts) {
    final full = await _annotationsDao.getById(row.id);
    if (full != null) annotations.add(_toAnnotationModel(full));
  }
  // 3. tag 过滤（AND）
  var filtered = annotations;
  if (tags != null && tags.isNotEmpty) {
    filtered = filtered.where((a) => tags.every(a.tags.contains)).toList();
  }
  // 4. color 过滤
  if (color != null) {
    filtered = filtered.where((a) => a.color == color).toList();
  }
  return filtered;
}

String _sanitizeFtsQuery(String query) {
  // 用户输入：'活着 意义' → '"活着" "意义"'（FTS5 多关键词 AND）
  return query
      .split(RegExp(r'\s+'))
      .where((s) => s.isNotEmpty)
      .map((s) => '"${s.replaceAll('"', '')}"')
      .join(' ');
}
```

## 9. 错误处理

| 场景 | 处理 |
|---|---|
| 选区捕获失败（offset 反查无解） | log warning + snackbar "无法定位选区，请重试"；不持久化 |
| 注入失败（HTML 解析异常） | log error + fallback 渲染无高亮 HTML；不阻塞阅读 |
| BookNote 不存在 | lazy create：`getNoteByBook` 返回 null 时调 `createEmptyNote` |
| FTS5 查询语法错误（`"`未闭合） | `_sanitizeFtsQuery` 兜底；失败返回空列表 + log |
| v3→v4 迁移失败 | drift `MigrationStrategy` 抛异常，AppDatabase 已包装 try/catch；用户看到错误对话框，提供"重置数据库"选项（M3.5 完善） |
| 删除 Annotation 时 drawer 已重建 | StateNotifier 用 `copyWith` 不可变 state，UI 自动 rebuild；竞态由 drift 序列化保证 |
| 重叠高亮（两个 Annotation 区间交叉） | 按 `createdAt` 早的优先，后到的截断（log warning）；本 sprint 不支持嵌套高亮 |

## 13. 决策记录

| 决策 | 选择 | 理由 |
|---|---|---|
| 渲染方案 | A：SelectableRegion + HTML 注入 | 保住 M2 HtmlWidget 投入；spike 验证风险可控 |
| Locator 类型 | 新增 `EpubRangeLocator` 独立类型 | 不污染现有 `EpubCfiLocator`（point）；sealed Locator 多态扩展自然 |
| Offset 坐标系 | chapter plain text 绝对 offset | 跨字体/主题/分页稳定；同步友好 |
| NotesDrawer 位置 | 右侧 | 与 TOC Drawer（左）对称；不冲突 |
| tags 自动补全源 | 复用 `book_tags` 表 | 不引入 annotation-only tag 体系；用户已有 tag 直接复用 |
| 重叠高亮处理 | createdAt 早的优先，后到截断 | 简单可预测；嵌套高亮 MVP 不需要 |
| 选区 offset 反查 | 文本搜索 fallback | SelectableRegion API experimental；offset 含义不稳；99% 场景可接受 |
| FTS5 触发器 | 手写 SQL（customStatement） | drift 2.18 FTS5 example 走 customStatement；`@DependsOn` 写法在 drift 2.18 不稳定 |
