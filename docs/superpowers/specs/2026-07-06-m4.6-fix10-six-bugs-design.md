# M4.6-fix10 — 阅读器六大稳定性/排版问题综合治理

**设计日期**：2026-07-06
**里程碑**：M4.6-fix10
**前置**：M4.6-fix9（commit ed6ab68）PDF 双页改写 + MD scroll；用户实测仍有 6 个问题
**spec 配对 plan**：`docs/superpowers/plans/2026-07-06-m4.6-fix10-six-bugs.md`

---

## Context（为什么做）

M4.6-fix9 之后用户报告 6 个新问题，全部阻塞正常阅读：

1. **PDF 双页**：fix9 的"双 PdfViewer 共享 sourceName"方案在用户实测中**仍然卡死**，导致整个 PDF 阅读体验不可用。用户决定**先还原到单页模式保稳定**，缩略图需同步。
2. **MD 排版**：fix9 把 MD 改成 scroll 模式后用户说"还是没解决"。用户提议**MD 仿 TXT 的技术逻辑加载**——TXT 能正常分页+双页，MD 一定卡在某个具体环节。
3. **EPUB 卡顿**：《一本书读懂财报》翻页经常卡住、目录不跳转。
4. **EPUB/TXT 双页跨页选区**：双页模式下选左页第 N 行，右页同行被一起选中。
5. **摘录滞后**：添加摘录当场看不到，要退出书架再打开才能看到。
6. **红色蒙层崩溃**：阅读区蒙上红色 + 导航条消失，必须重启软件。

这 6 个问题覆盖了 PDF/MD/EPUB/TXT 全格式、选区、摘录、崩溃兜底。是一次系统性的稳定性大修。

---

## Goals

- **G1**：PDF 强制单页（含移除手动 toggle 按钮），缩略图与主区翻页同步。
- **G2**：MD 仿 TXT 技术逻辑——按 `#` 切章 + 每行独立成 `<p>` + **走 paged + 双页**（与 TXT 一致），保留章节 TOC。
- **G3**：EPUB `_buildPaged` 的 O(N²) DOM 解析优化为整章解析一次复用（O(N)）。
- **G4**：双页模式下每页独立 `SelectionArea`，杜绝跨页选区串读。
- **G5**：摘录反应式订阅修复——首条摘录场景 stream 不再提前终结。
- **G6**：全局错误兜底——`ErrorWidget.builder` + `FlutterError.onError` + `runZonedGuarded`，build 异常不再红屏。

## Non-Goals

- 不重写 PDF 双页（fix9 失败，留给后续 milestone）。
- 不引入 markdown_widget 包（用户未选）。
- 不做章节级或 widget 级缓存（G3 只做单帧内的 DOM 复用）。
- 不改 Paginator 算法本身（仍按 plain text 偏移测高）。
- 不重构选区上报为多 region 架构（G4 用最小改动：双页模式下每页套独立 SelectionArea）。

## 根因分析（Phase 1 调查结论）

### R1：PDF 双页卡死根因（fix9 残留）

fix9 把 `#L`/`#R` 不同 sourceName 改为相同 sourceName，理论上 pdfrx 通过 `PdfDocumentRefKey` CanonicalizedMap 共享同一份 PdfDocument。**但用户实测仍卡死**。

可能残留原因（不再深挖，按用户要求直接还原单页）：
- pdfrx 2.4.4 的双 `PdfViewer` 实例（即使共享 PdfDocument）仍可能在 `_attach`/`_detach` 上有竞态；
- 左右 controller 的 `goToPage` 时序；
- `initialPageNumber` 在 `PdfViewer.data` 构造时的处理。

**结论**：不继续调查，按用户决策还原单页 + 移除 toggle。

### R2：MD 排版根因（与 TXT 的关键差异）

**TXT 工作良好的原因**（`text_book_loader.dart:68-83`）：
```dart
for (final rawLine in lines) {
  final line = rawLine.trim();
  if (line.isEmpty) continue;
  buf.write('<p>${_escapeHtml(line)}</p>');  // 每行独立成 <p>
}
```
- 每行独立成 `<p>`，无 `<br>`，无嵌套结构。
- Paginator 把每个 `<p>` 当一个段落测高，plain text 偏移与视觉换行一致 → 分页精准。

**MD 卡死的原因**（`markdown_book_loader.dart:124-179`）：
```dart
static String _markdownToHtml(String body) {
  final raw = md.markdownToHtml(_forceVisibleLineBreaks(body));
  return _stripImages(raw);
}
```
- 用 `package:markdown` 标准库转 HTML → 产出 `<ul>/<li>/<h3>/<pre>/<blockquote>` 等嵌套结构；
- `_forceVisibleLineBreaks` 给每行尾加 2 空格 → markdown 渲染成 `<br>` → 单段内有多个 `<br>`；
- Paginator 用 `TextPainter` 测 plain text 偏移，**`<br>` 不增加 plain text 偏移但增加视觉高度** → 测出来的高度比实际渲染矮 → 一页装得过多 → **内容溢出页面边界**（fix2/3/5/7 共 4 次失败的根因）。

**MD 仿 TXT 的方案**（用户选择）：
- 保留 `#`/`##` 切章（`MarkdownBookLoader.parseMarkdown` 不动）；
- **每章 body 不再用 markdown 标准库转 HTML**，改为仿 TXT 的"每行独立成 `<p>`"；
- 对常见 markdown 行内语法做**轻量保留**（可选）：`**粗体**`→`<strong>`、`*斜体*`→`<em>`、`` `代码` ``→`<code>`；
- 走默认 paged + 双页（移除 `setPaginationMode(PaginationMode.scroll)`）。

### R3：EPUB 翻页/目录卡死根因（O(N²) DOM 解析）

`_buildPaged`（`epubx_renderer.dart:1041-1207`）的 LayoutBuilder 内部，对每个 break 都调用 `HtmlSlicer.sliceByPlainRange`：

```dart
// html_slicer.dart:62
final doc = HtmlParser(html).parse();  // ← 每页都重新解析整章 DOM
```

一本长章节（如财经书表格多，单章 50+ 页）：
- 单帧内 LayoutBuilder 跑 50 次 `HtmlParser(html).parse()`；
- 每次 parse 整章 DOM 是 O(章 HTML 长度)；
- 加上 `_walkAndFilter` 的 DFS 遍历；
- **单帧 O(50 × 整章 DOM) = 数百 ms**，主线程被占满；
- 用户点翻页/目录 → 触发 rebuild → 又跑这一长循环；
- 同时 TOC `onSelect` 的 `await chapterSwitchSettled` 等的 post-frame callback 被这一帧堵住 → **看起来"卡住不动"**。

CHANGELOG M3e/Q12 已做过一次优化（把循环从 itemBuilder 上移到 LayoutBuilder），**但没消除"每页解析整章 DOM"的 O(N²) 本质**。

**修复**：整章 HTML 解析一次得到 `Document`，所有 break 复用这个 `Document` 的 clone（每个 break 的 walkAndFilter 会修改 DOM，需要 clone 或重建游标）。

### R4：双页跨页选区根因（单 SelectableRegion 包整树）

`reader_body.dart:548-552`：
```dart
SelectableRegion(
  key: _selectableRegionKey,
  selectionControls: materialTextSelectionControls,
  onSelectionChanged: _onSelectionChanged,
  child: ReaderScaffold(
    content: engine.build(innerContext),  // ← 整个 PageView（含双页 Row）都在这里
  ),
),
```

`epubx_renderer.dart:1190-1204` 双页模式：
```dart
return _DualSpreadAligner(
  child: Row(
    children: [
      Expanded(child: buildSinglePage(leftIdx, verticalMargin: 0)),
      SizedBox(width: gutterPx),
      Expanded(child: hasRight ? buildSinglePage(rightIdx, verticalMargin: 0) : SizedBox.shrink()),
    ],
  ),
);
```

机制：单个 `SelectableRegion` 建立**唯一** `SelectionRegistrar`，左右两页的 HtmlWidget 内所有 selectable 文本节点都注册到同一个 registrar。Flutter 按选区起止点的全局几何矩形求交，左右页同一 Y 行的文本都在这个矩形内 → **右页同行被一并选中**。

**修复**：双页模式下，每个 `Expanded` 内的 `buildSinglePage(...)` 套独立的 `SelectionArea`。Flutter 的 `SelectionArea` 内部建立局部 registrar，子树的 selectable 不冒泡到外层 `SelectableRegion`。

实现要点：
- epubx_renderer 的双页 Row 内，左右页各包一层 `SelectionArea`；
- 单页模式不包（保持现状）；
- `SelectionArea` 的 `onSelectionChanged` 转发到 renderer 的 `emitSelection` 流，reader_body 监听 renderer 的 selection$（已有，pdf 路径在用）；
- reader_body 的 toolbar / 选区上报改为：EPUB paged 双页模式下，监听 renderer 的 selection$ 而非自己的 SelectableRegion.onSelectionChanged。

### R5：摘录滞后根因（stream 提前终结）

`local_notes_repository.dart:193-202`：
```dart
Stream<List<Annotation>> watchAnnotations(String bookId) async* {
  final noteRow = await _notesDao.getByBookId(bookId);  // ← 一次性 Future，非反应式
  if (noteRow == null) {
    yield const <Annotation>[];
    return;  // ← BUG: stream 在这里终结
  }
  yield* _annotationsDao.watchByBookNoteId(noteRow.id).map(...);
}
```

时序还原（首条摘录场景）：
| t   | 动作 | stream 状态 |
|-----|------|-------------|
| t0  | reader page 打开，NotesController._init 注册 listener，`await getByBookId` → null | yield [] → **return，stream 关闭** |
| t1  | 用户点高亮 → `_ensureBookNote` 创建 BookNote 行 | stream 已死，收不到 |
| t2  | addAnnotation 插入 annotation | drift `watchByBookNoteId` 没被订阅 |

`getByBookId` 是 `getSingleOrNull()`（一次性 Future），BookNotes 表后续新增**不会**触发重发。

**修复**：`watchAnnotations` 不能在 noteRow==null 时 return。改成同时 watch 两个表——BookNotes 表的 `watchByBookId` stream + 出现后切换到 Annotations 表的 `watchByBookNoteId`。具体实现用 `Stream.switchIfEmpty` 或手写 `await for` + 状态机。

### R6：红色蒙层根因（无全局错误兜底）

`main.dart:34-81` 无 `ErrorWidget.builder`、`FlutterError.onError`、`runZonedGuarded`。

任何 widget 的 build 抛异常 → Flutter framework 默认行为：把抛异常的 element 替换成 `ErrorWidget`，**默认渲染就是红底白字**。

`reader_body.dart:543-589` 的 `_buildReaderStack` 把正文（PageView）+ chrome（导航条）放进**同一个 Stack**。一旦 Stack 根 build 抛异常 → 整棵子树被 ErrorWidget 替换 → **chrome 和正文一起消失** → 用户只看到一块红屏。

代码注释自己也提到过（`reader_page.dart:96-98` "Riverpod 断言红屏"），说明这是已知回归类别。

**修复**：
1. `ErrorWidget.builder = (details) => Material(...)` 把红屏替换成应用内的 ErrorView；
2. `FlutterError.onError` 记录到日志；
3. `runZonedGuarded` 包 `runApp`，捕获异步异常。

## Architecture Decisions

### A1：PDF 彻底锁死单页（用户决策）

`reader_body.dart:407` `e.dualPageMode = isWide && !e.rendererRef.isScanned;` → 改成 `e.dualPageMode = false;`。
`reader_body.dart:576-584` 的 `onToggleDualPage: engine is PdfReaderEngine ? () => ...` → 改成 `null`，同时 `isDualPageMode: false`。

效果：PDF 永远单页，ReaderScaffold 不再显示双页 toggle 按钮。

### A2：MD 仿 TXT——保留切章，body 转纯文本 HTML（用户决策）

改 `MarkdownBookLoader._markdownToHtml`：
- 不再调 `md.markdownToHtml()`；
- 不再调 `_forceVisibleLineBreaks`；
- 仿 TXT：按 `\n` 分行，每行 trim，空行跳过，每行独立成 `<p>`；
- **轻量保留行内语法**（提升可读性）：
  - `**text**` → `<strong>text</strong>`
  - `*text*` 或 `_text_` → `<em>text</em>`
  - `` `code` `` → `<code>code</code>`
  - `[text](url)` → `text`（剥离链接，保留文本）
- HTML 实体转义（与 TXT 一致）。
- 标题行（`#`/`##`）已在切章阶段处理，body 内不会出现 → 不需特殊处理。
- 列表项（`- `/`* `/`1. `）原样成 `<p>`，前缀保留（视觉上仍能看出是列表）。
- 代码块（` ``` ` 围栏）原样成 `<p>`，围栏符号保留。

改 `reader_engine_provider.dart:105`：移除 `await engine.setPaginationMode(PaginationMode.scroll);`，让 MD 走默认 paged + 双页（与 TXT 一致）。

### A3：EPUB 整章 DOM 解析一次复用

改 `html_slicer.dart` 的 `sliceByPlainRange`：
- 新增内部方法 `_sliceByPlainRangeDoc(Document doc, int pageStart, int pageEnd)`，接受预解析的 Document；
- `sliceByPlainRange` 仍解析整章（向后兼容），但内部委托给新方法；
- 关键：`_walkAndFilter` 会**修改** DOM（删除范围外节点），所以每次调用前要 `doc = originalDoc.clone(true)` 或者**重建游标 + 不修改 DOM，只采集要保留的节点**。

实现选择：**重构 `_walkAndFilter` 为非破坏式**——遍历整章 DOM 时记录每个文本节点的 plain 范围，对当前页面范围用过滤器重建一个**新的子树**（不修改原 doc）。这样：
- 整章 doc 解析一次；
- 每个 break 复用同一个不可变 doc；
- 每个 break 的输出是新构造的 HTML 片段。

改 `epubx_renderer.dart:1083-1109` 的预计算循环：
- 在循环外 `final doc = HtmlParser(html).parse();`；
- 循环内调 `_sliceByPlainRangeDoc(doc, start, end)`。

### A4：双页每页独立 SelectionArea

改 `epubx_renderer.dart:1190-1204`：
```dart
return _DualSpreadAligner(
  margin: margin,
  child: Row(
    crossAxisAlignment: CrossAxisAlignment.start,
    children: [
      Expanded(child: SelectionArea(
        onSelectionChanged: (sel) => _emitSelectionFromArea(sel),
        child: buildSinglePage(leftIdx, verticalMargin: 0),
      )),
      SizedBox(width: gutterPx),
      Expanded(child: hasRight
          ? SelectionArea(
              onSelectionChanged: (sel) => _emitSelectionFromArea(sel),
              child: buildSinglePage(rightIdx, verticalMargin: 0),
            )
          : const SizedBox.shrink()),
    ],
  ),
);
```

`_emitSelectionFromArea`：把 `SelectedContent` 转发到 renderer 的 `_selectionController`（已有）。

`reader_body.dart` 的 EPUB paged 双页路径：
- 外层 `SelectableRegion` 改为 `SelectionArea`（或保留 SelectableRegion 但 onSelectionChanged 改为 no-op，由 renderer selection$ 驱动）；
- 用 `ref.listen` 或 `engine.selection$.listen` 取代直接读 `_selection`；
- toolbar / 摘录 / 复制 handlers 改读 renderer 推下来的 selection。

**风险**：单页模式下，选区仍走 SelectableRegion，工具栏定位逻辑（`_selectableRegionKey.currentState.contextMenuAnchors`）保持原样。双页模式下没有 GlobalKey，工具栏定位需用 `selection$` 推上来的 rect（renderer 的 `_emitSelectionFromArea` 同时推 rect，需要在 SelectionArea 的 onSelectionChanged 里通过 `context.findRenderObject` 拿到选区矩形）。这块是工作量最大的部分，先简化处理（双页模式下工具栏固定顶部居中，后续优化）。

### A5：摘录反应式订阅修复

改 `local_notes_repository.dart:193-202` 的 `watchAnnotations`：
```dart
Stream<List<Annotation>> watchAnnotations(String bookId) async* {
  // 先尝试一次性查询 BookNote 是否已存在
  var noteRow = await _notesDao.getByBookId(bookId);
  if (noteRow != null) {
    yield* _annotationsDao
        .watchByBookNoteId(noteRow.id)
        .map((rows) => rows.map(_toAnnotationModel).toList());
    return;
  }
  // BookNote 不存在：同时订阅 BookNotes 表和（占位）等待出现
  // 用 bookNotesDao 的 watch stream（drift .watch()），出现 noteRow 后切换
  await for (final _ in _notesDao.watchByBookId(bookId)) {
    noteRow = await _notesDao.getByBookId(bookId);
    if (noteRow == null) {
      yield const <Annotation>[];
      continue;
    }
    // 出现了，切换到 annotations watch
    yield* _annotationsDao
        .watchByBookNoteId(noteRow.id)
        .map((rows) => rows.map(_toAnnotationModel).toList());
    return;
  }
}
```

需要新增 `book_notes_dao.dart` 的 `watchByBookId`（drift `.watch()`）。

## Risks

| Risk | Impact | Mitigation |
|------|--------|-----------|
| MD 行内语法正则误伤（如代码块内的 `**` 被替换） | MD 显示异常 | 在围栏代码块内禁用行内语法替换；测试覆盖常见 MD 文档 |
| A3 非破坏式 walkAndFilter 算法实现错误 | EPUB 内容缺失或重复 | 用现有 html_slicer_test.dart + 新增对照测试验证 |
| A4 双页 SelectionArea 工具栏定位不准 | 摘录/复制工具栏不跟随选区 | 双页模式下工具栏固定顶部居中，单页模式不变；后续 milestone 优化 |
| A5 watchAnnotations 改动后行为变化 | 影响 AI 摘录 / 笔记同步 | 用现有 notes_repository_test.dart 覆盖首条/后续场景 |
| A6 runZonedGuarded 改变启动时序 | 某些初始化失败 | 保留所有 init 调用顺序，只在外层包 zone |
| 用户实测 EPUB 卡顿在 G3 修复后仍未消除 | 性能问题在别处 | G3 是已知最大 O(N²)，先做；若仍卡补 LayoutBuilder 计时日志 |

## Success Criteria

- **SC1**：PDF 打开任意书籍（扫描件/数字版），主区永远单页显示，ReaderScaffold 工具栏**无双页 toggle 按钮**。
- **SC2**：PDF 翻页时，左侧缩略图 grid 的"当前页"高亮**实时跟随**主区翻页（无需关闭重开 drawer）。
- **SC3**：打开任意 MD 文件，章节 TOC 完整（按 `#`/`##` 切章），正文 paged 模式翻页流畅、无双页跨页溢出、段落不被切到页中。
- **SC4**：EPUB《一本书读懂财报》（或任意长章节书）翻页流畅、目录点击立即跳转，无卡顿。
- **SC5**：EPUB 双页模式下，选左页某几行**只选中左页**，右页同行不被选中；TXT 同样修复。
- **SC6**：对**新书**（尚无任何摘录）首次添加摘录后，notes drawer 立即出现该摘录，无需退出书架重进。
