## 1. 目标与范围

### 1.1 用户故事

- **作为读者**，我想在导入一本书后一键生成 300 字全书摘要，快速判断要不要读。
- **作为读者**，我在阅读时遇到不懂的段落，想选中后一键让 AI 解读。
- **作为读者**，我希望生成的摘要缓存起来，二次打开秒开，不要每次都烧 token。

### 1.2 In Scope

1. **OpenAI-compatible LLM client**（默认 DeepSeek，base_url 可配，支持流式 SSE）
2. **API key 管理**（`flutter_secure_storage` + Settings 子页）
3. **全书摘要**（head/mid/tail 1/3 截断到 ≤8K tokens，单 prompt 模型自适应语言）
4. **选区点评**（reader 内选中文字 → "AI 点评" 按钮 → 流式点评）
5. **三入口**：Library 长按菜单、Reader 顶栏菜单、BookDetailPage 主按钮
6. **摘要缓存**（drift `ai_summaries` 表，by `book_id + mode + sha256(source)`）
7. **错误 UX**：401 → 跳 Settings、429 → 手动重试、网络层 → 自动重试 3 次

### 1.3 Out of Scope（推到后续 spiral）

- **章节导读**（按章生成 1-2 句 → S4）
- **同书 Q&A + 引用**（→ S5）
- **跨书 AI 伴读**（phase 3，Settings 内留 disabled 占位）
- **成本估算 UI**（每次调用前显示 "约 X 元" → S4）
- **API 主动节流**（DeepSeek 限流比坚果云宽，429 由用户重试即可）
- **抽象 `LlmClient` interface**（OpenAI-compatible 已是事实标准，YAGNI）

## 2. 架构

### 2.1 分层（镜像 `services/sync/` + `features/sync/` 模式）

```
services/ai/
  open_ai_compatible_client.dart   # HTTP + SSE streaming 包装，无业务
  api_key_store.dart               # flutter_secure_storage（key + base_url + model）
  book_text_extractor.dart         # EPUB 读 chapters.spine html / PDF 用 pdfrx 抽
  token_truncator.dart             # head/mid/tail 1/3 切到 ≤8K tokens
  ai_guide.dart                    # 业务编排（mode=full | selection）
  prompt_builder.dart              # 全书摘要 prompt + 选区点评 prompt 模板

features/ai/
  providers/ai_guide_controller.dart  # Riverpod StateNotifier<AIStreamState>
  pages/api_key_settings_page.dart    # Settings 子页
  widgets/ai_guide_sheet.dart         # 流式输出 bottom sheet（两模式共用）
  widgets/ai_comment_button.dart      # reader 选区工具栏入口

data/local/tables/ai_summaries.dart        # 缓存表
features/ai/services/ai_summary_cache.dart # DAO
```

### 2.2 关键边界

- **`OpenAiCompatibleClient`**：只懂 HTTP/SSE，不懂 book / prompt；构造时注入 `http.Client` → 可单测 mock。
- **`AiGuide`**：编排 "取文本 → 截断 → 拼 prompt → stream → 落 cache"，是 sheet 唯一调用入口。
- **`BookTextExtractor`**：抽象 EPUB / PDF 差异，对外暴露 `Future<String> extract(Book)`。
- **`AiGuideController`**：只管状态机（idle / loading / streaming / done / error），UI 监听状态切换。
- **不抽象 `LlmClient` interface**：OpenAI-compatible 已是事实标准；要换 provider 改 base_url 即可。

### 2.3 与 sync 模块的关系

- **不复用 RateLimiter**：DeepSeek 限流（30 req/min）比坚果云宽，R2 mitigation 靠 429 → 用户手动重试。
- **不复用 SyncCredentials**：API key 是 AI 专用，命名空间独立（`zhiyue.ai.*` vs `zhiyue.sync.*`）。
- **复用 `flutter_secure_storage`**：同一 OS 级加密机制，不同 key namespace。

## 3. 组件

### 3.1 `OpenAiCompatibleClient`

```dart
class OpenAiCompatibleClient {
  OpenAiCompatibleClient({
    required String baseUrl,
    required String apiKey,
    String model = 'deepseek-chat',
    http.Client? httpClient,
    Duration timeout = const Duration(seconds: 30),
  });

  /// POST {baseUrl}/chat/completions with stream=true.
  /// Yields incremental content chunks (delta.content parsed from SSE).
  /// Throws:
  ///   - AiAuthException on 401/403
  ///   - AiRateLimitException on 429
  ///   - AiServerException on 5xx
  ///   - AiNetworkException on SocketException / TimeoutException
  Stream<String> streamChat({required String prompt});
}
```

**实现要点**：
- `Authorization: Bearer <apiKey>` header
- Body: `{"model": model, "messages": [{"role":"user","content":prompt}], "stream": true}`
- 解析 SSE：每行 `data: {...}` → JSON 解出 `choices[0].delta.content`
- 终止：`data: [DONE]`
- 不做 retry（上层 `AiGuide` 决定哪些异常重试）

### 3.3 `BookTextExtractor`

```dart
abstract class BookTextExtractor {
  Future<String> extract(Book book);
}

class EpubTextExtractor implements BookTextExtractor {
  // 读 chapters.spine html → strip tags → concat
}

class PdfTextExtractor implements BookTextExtractor {
  // 用 pdfrx PdfDocument.openFile(path) → 遍历 doc.pages
  // 每页 page.loadText() → PdfPageRawText? → 取 .fullText → concat
}

class EmptyTextException implements Exception {}  // 扫描 PDF / 空 EPUB

BookTextExtractor extractorFor(Book book);  // 工厂：by book.format
```

**实现要点**：
- EPUB：复用 M3.2 已建立的 chapters 表（`html_content` 列） → 去标签拼接
- PDF：用 pdfrx `PdfDocument.openFile(path)` → 遍历 `pages[i].loadText()` → 拼接
- 全空文本（扫描 PDF / 空 EPUB）→ 抛 `EmptyTextException`
- 不持久化抽取结果（每次 AI 导读重新抽；PDF 抽取 1-3s 可接受）

### 3.4 `TokenTruncator`

```dart
class TokenTruncator {
  static const int defaultBudget = 8000;

  /// Truncates to ~maxTokens tokens using head/middle/tail 1/3 split.
  /// Token estimate: CJK char = 1 token, non-CJK 4 chars = 1 token.
  static String truncateToTokens(String text, int maxTokens);
}
```

**实现要点**：
- 启发式估 token：遍历 chars，`一-鿿` 算 1，其他 4 字符算 1
- 超预算时：head 1/3 + `…（省略 N 字）…` + mid 1/3 + `…（省略 N 字）…` + tail 1/3
- 不超预算时：原样返回
- 不引第三方 tokenizer 包（YAGNI）

### 3.5 `AiGuide`（编排核心）

```dart
class AiGuide {
  AiGuide({
    required ApiKeyStore apiKeys,
    required BookTextExtractor Function(Book) extractorFor,  // 工厂：根据 book.format 选 impl
    required AiSummaryCache cache,
    http.Client? httpClient,  // 测试注入
  });

  /// mode=full: book 必填；selection 必为 null
  /// mode=selection: book + selection 必填；chapterTitle 可选（由 caller 注入）
  Stream<AiGuideEvent> run({
    required Book book,
    required AiGuideMode mode,
    String? selection,
    String? chapterTitle,
  });
}

enum AiGuideMode { full, selection }

sealed class AiGuideEvent {}
class AiChunkEvent extends AiGuideEvent { final String chunk; }
class AiCompleteEvent extends AiGuideEvent { final String fullText; bool fromCache; }
class AiErrorEvent extends AiGuideEvent { final AiGuideError error; }

// AiGuideError 分类：
//   - noApiKey
//   - authFailed (401/403)
//   - rateLimited (429)
//   - serverError (5xx)
//   - network (SocketException/Timeout, 已重试 3 次)
//   - emptySource (扫描 PDF)
//   - parseError (SSE 解析失败)
//   - cancelled (用户主动取消)
```

**编排逻辑**：
1. `ApiKeyStore.load()` → null → emit `AiErrorEvent(noApiKey)`
2. mode=full: `sourceText = await extractor.extract(book)`；mode=selection: `sourceText = selection!`
3. `sourceHash = sha256(sourceText)`
4. `cache.find(book.id, mode, sourceHash, PromptBuilder.promptVersion)` → HIT → emit `AiCompleteEvent(cached, fromCache: true)` → 结束
5. MISS:
   - mode=full: `truncated = TokenTruncator.truncateToTokens(sourceText, 8000)` → `prompt = PromptBuilder.fullBook(truncated)`
   - mode=selection: `prompt = PromptBuilder.selection(selection, chapterTitle)`（chapterTitle 由 caller 注入，可能为 null）
   - `client = OpenAiCompatibleClient(baseUrl, apiKey, model, httpClient)`
   - state → streaming
   - try {
       accumulated = ''
       await for (chunk in client.streamChat(prompt)) {
         accumulated += chunk;
         emit AiChunkEvent(chunk);
         if (cancelled) { emit AiCompleteEvent(accumulated, fromCache:false); cache.insert(...); return; }
       }
       cache.insert(book.id, mode, sourceHash, accumulated, model, baseUrl, promptVersion);
       emit AiCompleteEvent(accumulated, fromCache:false);
     } catch (e) {
       map exception → AiErrorEvent(...)
       // 网络异常自动重试 3 次（指数退避 1s/2s/4s），其他异常不重试
       // streaming 中错误：不落 cache
     }

### 3.6 `AiSummaryCache`（drift DAO）

**Schema**（schemaVersion 6 → 7）：

```sql
CREATE TABLE ai_summaries (
  id              INTEGER PRIMARY KEY AUTOINCREMENT,
  book_id         INTEGER NOT NULL REFERENCES books(id) ON DELETE CASCADE,
  mode            TEXT NOT NULL,           -- 'full' | 'selection'
  source_hash     TEXT NOT NULL,           -- sha256(sourceText)
  summary_text    TEXT NOT NULL,
  model_name      TEXT NOT NULL,
  base_url        TEXT NOT NULL,
  generated_at    INTEGER NOT NULL,        -- millis since epoch
  prompt_version  INTEGER NOT NULL
);

CREATE INDEX idx_ai_summaries_lookup ON ai_summaries(book_id, mode, source_hash, prompt_version);
```

**DAO 方法**：
```dart
class AiSummaryCache {
  Future<AiSummary?> find({required int bookId, required String mode, required String sourceHash, required int promptVersion});
  Future<void> insert({...});
  Future<void> purgeForBook(int bookId);  // 书删除时级联（drift ON DELETE CASCADE 已覆盖）
}
```

**命中规则**：`book_id + mode + source_hash + prompt_version` 全等 → 命中。

### 3.7 `PromptBuilder`

```dart
class PromptBuilder {
  static const int promptVersion = 1;

  static String fullBook(String truncatedText) {
    return '''请用与原文相同的语言，用约 300 字总结以下书籍的核心论点和主要观点。
只输出总结，不要任何前置说明。

--- 原文（可能已截断）---
$truncatedText
--- 原文结束 ---''';
  }

  static String selection(String selectedText, {String? chapterTitle}) {
    final ctx = chapterTitle == null ? '' : '（用户正在阅读章节：$chapterTitle）\n';
    return '''请用与原文相同的语言，简洁地解读以下读者选中的文字$ctx。
重点解释含义、上下文、可能的引申，不超过 200 字。

--- 选中文字 ---
$selectedText
--- 选中文字结束 ---''';
  }
}
```

## 5. 数据流

### 5.1 路径 A：全书摘要

```
1. 入口触发
   - Library 长按 → "AI 导读"
   - Reader 顶栏 → auto_awesome icon
   - BookDetailPage → "AI 导读" 按钮

2. showModalBottomSheet(AiGuideSheet(book, mode: full))
   → AiGuideController.startFullBook(book)
   → AiGuide.run(book, mode: full)
       ├─ ApiKeyStore.load() → null?
       │    └─ YES: emit AiErrorEvent(noApiKey) → sheet 显示 "去设置"
       ├─ sourceText = await EpubTextExtractor.extract(book)  // 或 Pdf
       ├─ sourceHash = sha256(sourceText)
       ├─ cache.find(book.id, 'full', sourceHash, 1)?
       │    └─ HIT: emit AiCompleteEvent(cached, fromCache:true)
       └─ MISS:
            ├─ truncated = TokenTruncator.truncateToTokens(sourceText, 8000)
            ├─ prompt = PromptBuilder.fullBook(truncated)
            ├─ accumulated = ''
            ├─ await for chunk in client.streamChat(prompt):
            │    ├─ accumulated += chunk
            │    └─ emit AiChunkEvent(chunk)
            ├─ cache.insert(book.id, 'full', sourceHash, accumulated, ...)
            └─ emit AiCompleteEvent(accumulated, fromCache:false)
```

### 5.2 路径 B：选区点评

```
1. Reader 选中文字 → highlight toolbar 弹起 → 点 "AI 点评"

2. showModalBottomSheet(AiGuideSheet(book, mode: selection, selection: text))
   → AiGuideController.startSelection(book, text, chapterTitle: currentChapter)
   → AiGuide.run(book, mode: selection, selection: text, chapterTitle: currentChapter)
       // currentChapter 由 reader_page 从当前 chapterIndex 解析后传入
       // 如章节标题未知（如 PDF 无 TOC）→ 传 null，PromptBuilder.selection 省略上下文行
       ├─ ApiKeyStore.load() → null? → emit AiErrorEvent(noApiKey)
       ├─ sourceHash = sha256(text)
       ├─ cache.find(book.id, 'selection', sourceHash, 1)?
       │    └─ HIT: emit AiCompleteEvent
       └─ MISS:
            ├─ prompt = PromptBuilder.selection(text, chapterTitle)
            ├─ stream 同上
            └─ cache.insert
```

### 5.3 取消语义

- **关闭 X（短按）**：emit complete with accumulated → 写 cache（用户读了多少就有多少）。下次打开同 source 秒开。
- **关闭 X（长按）**：emit idle → 不写 cache（清坏摘要路径）。
- **取消 vs 错误**：用户主动取消落 cache；streaming 中收到 HTTP 异常 **不落** cache（避免半截坏文本）。

### 5.4 缓存命中流程

```
sheet 打开 → controller.startFullBook(book)
   ├─ HIT: 立刻显示完整文本（无 streaming），底部 "重新生成" 按钮可见
   │    └─ 用户点 "重新生成" → 强制走 MISS 路径 + 覆盖 cache（INSERT OR REPLACE）
   └─ MISS: spinner → streaming 渲染 → done
```

## 6. 错误处理

### 6.1 HTTP 异常分类

| HTTP / 异常 | `AiGuideError` | 用户文案 (i18n key) | 操作 |
|---|---|---|---|
| 401 / 403 | `authFailed` | `aiErrorAuthFailed` | "去设置" 按钮 → `/settings/ai` |
| 429 | `rateLimited` | `aiErrorRateLimited` | "重试" 按钮（用户手动） |
| 5xx | `serverError` | `aiErrorServer` | "重试" 按钮 |
| SocketException / TimeoutException | `network` | `aiErrorNetwork` | **自动重试 3 次**，1s/2s/4s 退避 |
| `EmptyTextException` | `emptySource` | `aiErrorEmptySource` | 关闭，无重试 |
| SSE 解析失败 | `parseError` | `aiErrorParse` | 保留已收到内容 + "继续生成" 按钮 |
| 无 API key | `noApiKey` | `aiErrorNoKey` | "去设置" 按钮 |

### 6.2 重试边界

- **只对网络层异常**（SocketException / TimeoutException）自动重试，最多 3 次，指数退避。
- **不对 HTTP 4xx/5xx 自动重试**：怕加重 API 负担，且 401 重试无意义。
- **用户手动重试**：sheet 内 "重试" 按钮永远可用（除 `noApiKey` / `emptySource`）。

### 6.3 API key 安全（R3 mitigation）

- `flutter_secure_storage`（Windows DPAPI / Android Keystore）
- 不写 `print` / `log` / 任何 analytics
- `OpenAiCompatibleClient` 构造时注入 key，不通过环境变量
- Settings 页 key 字段默认 obscure，需点 "显示" 才明文
- 不截屏（Sheet 暴露的是模型输出，不含 key）

### 6.4 Prompt 版本化

- `PromptBuilder.promptVersion = 1` 常量
- 写 cache 时存 `prompt_version`；改 prompt 时 bump 版本号 → 旧缓存自然失效（query 加 `AND prompt_version = ?`）

### 6.5 i18n 错误文案

所有错误文案进 `app/lib/gen_l10n/app_localizations*.dart` + `app/lib/l10n/app_{zh,en}.arb`（避免 T15 status label bug 覆辙）。预计 ~12 个新 key。
