    智阅（ZhiYue）使用说明书

    面向深度阅读和学习的本地优先电子书阅读器。
    所有数据存储在您的设备本地，完全离线可用；可选地启用 AI 陪伴式导读和跨设备同步。

    1. 功能概览

    💾
    本地优先

    全部数据存储在本机 SQLite，完全离线可用，隐私可控。

    📖
    多格式支持

    EPUB 完整功能 + PDF（文本版 + 扫描版阅读）。

    🎨
    沉浸阅读

    4 套主题、5 款中文字体、字号/行距/边距自定义、桌面双页对开。

    🖍️
    笔记系统

    5 色高亮 + 笔记 + 标签 + 全文搜索（FTS5）。

    🔖
    智能书签

    章节级书签，标签自动取自章节名（含译者序/引言）。

    📝
    自由笔记

    不绑定书页的独立 Markdown 笔记，可 @-mention 书中内容。

    🤖
    AI 陪伴导读

    全书摘要 / 章节导读 / 高亮点评 / 同书问答 / 苏格拉底追问。

    ☁️
    跨设备同步

    坚果云 / 任意 WebDAV。高亮、笔记、AI 对话、书籍文件、封面全覆盖。

    📤
    Markdown 导出

    Obsidian vault 兼容，YAML frontmatter + wiki-links + 标签云。

    2. 系统要求

    Windows

    • Windows 10 64 位 或 更高版本（推荐 Windows 11）
    • 至少 500 MB 可用磁盘空间
    • 1024 × 768 或更高分辨率

    Android

    • Android 8.0（API 26）或更高版本
    • 至少 200 MB 可用磁盘空间
    • 启用「允许安装未知来源应用」权限

    3. 安装

    3.1 Windows

    智阅提供两种 Windows 分发方式，按需选择其一。

    方式 A：安装版（推荐）

    文件名：zhiyue-setup-1.11.9-alpha.exe

    ✨ 特点
    • 自动注册 .epub / .pdf 文件关联
    • 添加开始菜单快捷方式
    • 包含卸载向导
    • 双击电子书文件自动用智阅打开（已运行时在原窗口打开）
    1. 双击 zhiyue-setup-1.11.9-alpha.exe
    2. 按安装向导提示选择安装目录（默认 %LOCALAPPDATA%\Programs\zhiyue）
    3. 完成后从开始菜单「智阅」启动，或双击任意 .epub / .pdf

    方式 B：便携版

    文件名：zhiyue-portable-1.11.9-alpha.zip

    解压即用，免安装，可放在 U 盘里随身携带。

    1. 解压 ZIP 到任意目录（例如 D:\Tools\zhiyue）
    2. 双击 zhiyue.exe 启动
    ⚠️ 注意
    便携版不自动注册文件关联。若希望双击 .epub 用智阅打开，请用安装版。

    3.2 Android

    文件名：zhiyue-1.11.9-alpha.apk

    1. 允许未知来源（首次安装需要）
      系统设置 → 应用 → 特殊访问权限 → 安装未知应用 → 选浏览器/文件管理器开启
    2. 传输 APK 到手机
      浏览器直接下载 / 数据线 / 蓝牙 / 微信 / 网盘
    3. 点击安装
      文件管理器点击 APK → 安装 → 打开

    启动后能看到智阅书架页面即成功（首次为空，提示导入第一本书）。

    4. 首次启动

    4.1 主界面布局

    智阅启动后进入书架页面（Library）。

    桌面版（Windows）

    ┌────────────────────────────────────────────────────────┐
│ 智阅            [搜索]    [同步]   [导入]  [溢出菜单]  │
├────────────────────────────────────────────────────────┤
│   [书] [书] [书] [书] [书]                              │
│   [书] [书] [书] [书] [书]                              │
└────────────────────────────────────────────────────────┘

    移动版（Android）

    ┌──────────────────────┐
│ ☰  智阅    [同步][+] │
├──────────────────────┤
│  [书] [书] [书]       │
│  [书] [书] [书]       │
└──────────────────────┘
    💡 提示
    左上角 ☰（汉堡菜单）打开抽屉，含设置、笔记、自由笔记等入口。

    4.2 推荐首次配置顺序

    1. 设置 → 外观 → 选择主题（亮 / 暗 / 护眼 / 电子墨水）
    2. 设置 → 排版预设 → 创建偏好的字号、行距、边距预设
    3. 设置 → 字体管理 → 可选：导入第三方中文字体（.ttf / .otf）
    4. 设置 → AI 导读 → 可选：填入 API key 启用 AI 功能（详见 第 11 节）
    5. 设置 → 数据同步 → 可选：配置 WebDAV 启用跨设备同步（详见 第 12 节）
    6. 导入书籍（详见 第 5 节）

    5. 导入电子书

    5.1 通过书架 + 按钮

    1. 书架页面右上角点击 + 按钮
    2. 选择 .epub 或 .pdf 文件
    3. 等待导入（大书可能需要几秒，AI 索引在后台进行）

    5.2 通过文件关联（仅 Windows 安装版）

    直接在文件管理器中双击 .epub / .pdf → 智阅自动启动并导入。若智阅已在运行，新书会在原窗口打开，不会启动第二个进程。

    5.3 通过 Android 文件管理器

    在 Android 文件管理器中点击 .epub / .pdf → 选择「智阅」打开。

    5.4 支持的格式

    格式阅读高亮笔记章节切分
    EPUB✅✅✅✅
    PDF（文本版）✅✅✅✅（按页）
    PDF（扫描版）✅❌❌✅（按页）

    5.5 重复导入

    • 同一文件（基于内容 hash）重复导入会自动识别，不会重复上架
    • 若删除后再导入提示 errno=5，通常是 Windows 文件 ReadOnly 属性，重新导入会自动清 ReadOnly 重试

    6. 阅读基础

    点击书架任意书籍封面进入阅读器。

    6.1 翻页（多种输入方式）

    输入方式操作
    键盘← → ↑ ↓ PgUp PgDn
    鼠标滚轮滚动
    触摸拖拽左右滑动
    Tap zone（触摸）屏幕左侧 1/3 = 上一页，右侧 1/3 = 下一页
    翻页按钮EPUB paged 模式专用底部按钮

    6.2 章节导航

    点击顶部目录图标（☰ 或 list）打开目录抽屉：

    • 目录（TOC）：列出所有章节，点击跳转
    • 书签：当前书的全部书签
    • 笔记：当前书的全部高亮 + 笔记
    💡 宽屏侧栏
    宽屏（≥ 1100px）下目录抽屉会自动升级为永久侧栏，可折叠至 40px。

    6.3 显示 / 隐藏 chrome（顶栏 + 底栏）

    阅读时点击屏幕中部（双击）可切换显示状态：

    • 桌面：顶栏（书名 / 章节 / 操作按钮）+ 底栏（进度条）
    • 移动：3 秒后自动隐藏，任意触摸操作唤回

    6.4 全屏模式

    平台快捷键
    WindowsF11 或 Esc
    Android顶栏 overflow 菜单 → 全屏

    全屏态下双击屏幕中部可临时显示 chrome。

    6.5 进度条

    底部进度条显示当前章节内的位置百分比。拖动 = 章节内快速定位；跨章节请用目录抽屉。

    6.6 双页对开

    • 桌面：屏幕宽度 ≥ 1100px 自动启用双页布局（左偶右奇）
    • PDF：宽度 ≥ 1200px 自动启用双页（扫描件自动降级为单页）
    • EPUB：双页渲染层为 v1.6 引入，可在阅读器顶栏手动开关

    6.7 章节结束提示（EPUB）

    翻到一章末页时弹出非阻塞 SnackBar，提供：

    • 回顾本章：触发 AI 章节回顾（需配置 AI）
    • 下一章：跳转
    • 关闭：忽略

    设置 → 阅读 → 可全局开关。PDF 不弹（pdfrx Page-as-Chapter 模式过于频繁）。

    6.8 TTS 朗读（v1.12+）

    智阅内置 TTS 朗读引擎，支持 AI 响应朗读与书籍章节自动跟读，移动端可后台播放。

    6.8.1 AI 响应朗读

    在 AI 聊天消息上长按 → 弹出菜单 → 选「朗读」。

    • 底部出现 TtsMiniControls 浮窗
    • 支持：暂停 / 继续 / 上一句 / 下一句 / 停止
    • 显示当前句子预览 + 进度条

    6.8.2 章节自动跟读（EPUB / TXT / Markdown）

    Reader 顶部 chrome 点 「朗读本章」 图标（record_voice_over）：

    • 从本章开头自动朗读
    • paged 模式自动翻页；scroll 模式自动滚动
    • 当前句子金黄高亮（区别于用户高亮，3 秒淡出，不写入数据库）
    • 手动翻页会自动暂停 TTS，顶部出现「上次朗读到 第 N 章 [继续]」横幅（5 秒后自动隐藏）

    6.8.3 PDF 选中文本朗读

    PDF 中选中一段文字 → 工具条点 「朗读选中」：

    • 仅朗读该段，不进入章节模式
    • 适用任意格式（EPUB / PDF / TXT / Markdown）

    6.8.4 章节边界设置

    设置 → 朗读 → 「章节结束行为」二选一：

    模式行为
    连续（默认）当前章节结束自动进入下一章
    章末询问弹出 SnackBar「继续 / 停止」

    6.8.5 移动端后台播放

    Android / iOS 上朗读时：

    • 锁屏可见媒体控件（播放 / 暂停 / 上一句 / 下一句 / 停止）
    • 拔耳机或来电自动暂停
    • Android foreground service 保活通知（Android 14+ 需 FOREGROUND_SERVICE_MEDIA_PLAYBACK 权限，已自动配置）
    • iOS UIBackgroundModes: audio（已配置）
    💡 平台差异
    桌面（Windows）不启用 audio_service，仅前台朗读。

    6.8.6 检查 TTS 引擎（建议首次使用前）

    设置 → 朗读 → 「检查 TTS 引擎」 按钮 → 弹窗显示 4 种状态：

    状态说明
    就绪引擎装了 + 语音数据齐，可以开始朗读
    引擎缺失完全没装 TTS 引擎，需装 Google TTS
    语音数据未下载引擎在但缺语音数据，需到系统 TTS 设置下载对应语言
    Samsung 引擎受限检测到 com.samsung.SMT，中文支持受限。建议切换到 Google TTS 或在 Samsung Voice Assistant 下载中文语音
    ⚠️ Samsung 用户
    Samsung 设备首次使用前强烈建议跑一次此检查——SMT 引擎对中文支持差，会让朗读体验明显劣化。

    6.8.7 跨设备位置同步

    朗读时当前章节 + 句子序号自动记录到 books.last_tts_position，通过坚果云同步到其他设备。

    在新设备打开同一本书时，TtsResumePrompt 显示上次朗读位置（章节号 + [继续] 按钮）。

    📝 同步粒度
    受 books 表无 updated_at 限制，位置走整 book payload 同步（与封面同步同限制）。多设备并发朗读同书时最后写入者获胜——可接受，朗读是单人活动。

    7. 排版设置

    7.1 即时调整

    阅读器顶栏点击字号图标（Aa）打开排版面板：

    项范围默认
    字号12 - 32 px18 px
    行距1.2 - 2.41.6
    段距0 - 24 px12 px
    左右边距Compact(8) / Normal(24) / Wide(40)Normal（移动端 Compact）
    首行缩进0 / 2 em2 em（中文）
    对齐左 / 两端两端
    ✨ 即时生效
    改动即时生效并自动保存。

    7.2 排版预设

    每本书的排版可以独立保存，也可以保存为预设共享给其他书。

    设置 → 排版预设：

    • 创建多个预设（例如「白天看书」「睡前大字」「墨水屏」）
    • 每本书的排版面板顶部可一键切换预设
    • 切换预设不影响该书的高亮、笔记、进度

    7.3 字体

    设置 → 字体管理：

    • 查看内置字体（黑体 / 宋体 / 楷体 / 普惠体 / 新晰黑）
    • 导入第三方字体：支持 .ttf / .otf / .ttc
    • 字体仅在 EPUB 生效（PDF 字体由原文件决定）

    8. 高亮与笔记

    8.1 创建高亮

    1. 在阅读页面长按或鼠标拖选一段文字
    2. 选中后弹出摘录工具条：
      • 5 种颜色：黄 / 绿 / 蓝 / 粉 / 紫
      • 笔记输入：点击「笔记」按钮，弹出输入框
      • 标签：可在笔记对话框中添加
    3. 点击颜色或确认 → 高亮写入数据库

    8.2 编辑 / 删除高亮

    再次点击已高亮的文字 → 弹出编辑菜单：修改颜色 / 添加笔记 / 添加标签 / 删除。

    8.3 查看全部笔记

    阅读器抽屉 → 笔记 tab：列出当前书所有高亮 + 笔记。点击任意一条 → 跳转到对应位置。

    8.4 全局笔记库

    桌面抽屉 / 移动 hamburger 菜单 → 笔记：跨所有书的笔记总览，支持按标签筛选、按颜色筛选、全文搜索（FTS5）。

    8.5 全文搜索

    笔记库页面顶部搜索框：

    • 支持 quote（原文）/ note（笔记内容）/ tags（标签）三字段子串匹配
    • CJK 友好：可搜「活着」命中「人是为了活着本身而活着」
    • v1.11.10 起：用户输入的 % 和 _ 当字面量匹配，不被当作通配符

    9. 书签

    9.1 添加书签

    阅读器顶栏点击书签图标（旗帜或 bookmark_border）：

    • 弹出书签对话框，可编辑标签
    • 默认标签自动取自当前章节名（例如「译者序」「第一章 众妙之门」），不再显示「第 N 章」
    • 点击「保存」

    9.2 查看书签

    阅读器抽屉 → 书签 tab：列出当前书所有书签。点击任意一条 → 跳转到原位置。

    9.3 删除书签

    • 抽屉书签 tab → 滑动删除（移动）/ 右键菜单（桌面）
    • 或在书签对应位置顶栏再次点击书签图标 → 移除

    9.4 跨设备同步

    书签会通过 WebDAV 自动同步到其他设备（详见 第 12 节）。

    10. 自由笔记

    自由笔记是不绑定书页的独立 Markdown 笔记，可用于：

    • 读书心得整理
    • 跨书主题笔记
    • 临时灵感记录

    10.1 创建自由笔记

    入口：

    • 桌面抽屉 / 移动 hamburger 菜单 → 自由笔记 → 右下角 FAB +
    • 阅读器 AI 抽屉 → 顶部 note_add 图标

    10.2 编辑

    • Markdown 实时预览（编辑/预览双 tab）
    • 自动保存（500ms debounce write-through）
    • 可 @-mention 书中高亮：@note-xxx 会插入引用

    10.3 跨设备同步

    自由笔记会通过 WebDAV 自动同步。

    11. AI 陪伴导读

    11.1 配置（BYOK 模式）

    智阅使用 Bring Your Own Key 模式，您需要自带 LLM API key。

    1. 获取 API key
      默认推荐 DeepSeek（https://platform.deepseek.com）。注册后在「API Keys」页面创建 key（形如 sk-xxxxxxxx）。充值按 token 计费，DeepSeek 价格约为 ¥1 / 百万 token。
    2. 填入智阅：设置 → AI 导读
      • Base URL：https://api.deepseek.com/v1（DeepSeek 默认）
      • API Key：粘贴您的 sk-...
      • Model：deepseek-chat（默认）或 deepseek-reasoner
      • 点「测试连接」→ 提示成功即配置完成
    💡 兼容性
    智阅兼容任何 OpenAI-compatible API（DeepSeek / 通义千问 / Kimi / 智谱 / OpenAI 官方等），改 Base URL 即可。
    Base URL 必须是 HTTPS（HTTP 公网地址会弹窗二次确认，localhost / 内网 IP 豁免）。

    11.2 五种 AI 入口

    智阅把 5 个分散的 AI 入口收敛为1 个统一抽屉（v1.7+）。阅读器顶栏点击 smart_toy_outlined 图标打开 AI 抽屉。

    A. 全书摘要

    「请给我这本书的全书摘要」 → AI 用书的元数据 + 章节大纲生成 ~500 字摘要。

    B. 章节导读

    阅读时打开 AI 抽屉 → 输入「本章导读」 → AI 用当前章节正文生成：本章核心论点、关键概念、推荐读法。

    C. 高亮点评

    选中文字 → 创建高亮 → AI 抽屉顶部出现「点评此高亮」按钮 → AI 对该段文字做延伸解读。

    D. 同书问答（带 [ch=N] 跳转）

    您：作者在[ch=3]讲的「无为」是什么意思？
AI：根据第三章正文，"无为"指的是……
    [ch=3] ← 点击可跳转到第三章对应位置
    • [ch=N] 是章节引用语法，AI 输出和您的输入都支持
    • 点击 [ch=N] 自动跳转到第 N 章

    E. 苏格拉底式追问

    输入 /苏格拉底 或 /socratic 开启苏格拉底模式：AI 不直接给答案，而是反问引导您思考。适合哲学 / 思辨类书籍。

    11.3 Slash 命令

    命令作用
    /new新建一个会话
    /del删除当前会话
    /switch切换到其他会话
    /苏格拉底开启苏格拉底模式

    11.4 多会话管理

    每本书可以有多个 AI 会话：

    • 抽屉顶部下拉切换会话
    • 每个会话独立保留上下文
    • 会话与书绑定，不会串扰其他书

    11.5 @-note 提及

    AI 抽屉输入框中输入 @ 弹出笔记选择器：选择笔记 → AI 会读入笔记内容作为上下文。适合「让我之前对这段的笔记来回答这个问题」。

    11.6 流式响应与取消

    • AI 回复流式渲染（边生成边显示）
    • 长回复可点击「取消」按钮中断
    • 中断后已生成的部分保留

    11.7 跨设备同步

    AI 会话历史（chat_sessions / chat_messages）通过 WebDAV 自动同步。手机上问的问题，桌面打开能接着聊。

    11.8 隐私说明

    🔒 隐私
    • 您的 API key 加密存储在本机 flutter_secure_storage，不会上传到智阅服务器（项目无服务器）
    • 书籍正文 + 您的高亮 / 笔记 / 提问会发送给您配置的 LLM 服务商（DeepSeek / 其他）
    • 智阅本身不记录、不中转、不存储您的 AI 对话内容
    • 如果不希望某些书的内容上传，请关闭 AI 功能或使用本地 LLM（如 Ollama，配置 Base URL http://localhost:11434/v1）

    12. 跨设备同步

    12.1 同步原理

    智阅采用分布式快照 + 最后写入胜（last-write-wins）模型：

    • 每台设备在 WebDAV 上维护自己的快照 /zhiyue/snapshots/<deviceId>.jsonl
    • 设备 A 写入 → push 到自己的快照
    • 设备 B 拉取 → 读所有设备的快照 → 按 updatedAt 时间戳决定哪个版本赢
    • 冲突（同一条记录在多设备同时改）会在「冲突日志」中提示
    📦 同步内容
    书籍元数据、高亮、笔记、自由笔记、书签、阅读进度、AI 对话、标签、书籍文件（EPUB/PDF binary）、封面。

    12.2 配置坚果云（推荐）

    坚果云是国内访问稳定的 WebDAV 服务商，免费版限 600 次/30 分钟请求。

    步骤 1：创建 zhiyue 文件夹

    登录 https://www.jianguoyun.com → 进入「我的资料」根目录 → 手动创建名为 zhiyue 的文件夹（全小写，无空格）。

    ⚠️ 必须
    若不创建，首次同步会报 409 AncestorsNotFound。

    步骤 2：生成应用密码

    账户信息 → 安全选项 → 第三方应用管理 → 「添加应用」→ 命名「智阅」→ 复制生成的应用密码（不是登录密码）。

    步骤 3：填入智阅

    设置 → 数据同步：

    字段值
    WebDAV baseUrlhttps://dav.jianguoyun.com/dav/
    账号坚果云邮箱全称（例：user@example.com）
    密码步骤 2 生成的应用密码

    点「立即同步」→ 首次同步成功后显示「同步成功」+ 时间戳。

    12.3 同步状态图标

    状态图标说明
    idle🔄 sync空闲，点击触发同步
    pushing🔄 sync（旋转）上传中
    pulling🔄 sync（旋转）下载中

    12.4 自动同步时机

    智阅会在以下时机自动触发同步：

    1. 任何写操作 3 秒后（debounce）—— 加书签、写笔记、改进度等
    2. 关闭应用前（best-effort，最多等 3 秒）—— 解决「加书签 5 分钟内关机丢失窗口」
    3. 冷启动—— 打开智阅立即拉取其他设备的最新状态
    💡 覆盖范围
    这三层对所有 9 种 record type（书籍 / 书签 / 笔记 / AI / 高亮 / 进度 / 标签 / 自由笔记 / 书籍文件）都生效。

    12.5 手动同步

    • 书架顶栏点击同步按钮

    12.6 冲突处理

    1. 自动采用 last-write-wins（最后修改的版本赢）
    2. 旧版本不删除，记录在「冲突日志」
    3. 设置 → 数据同步 → 冲突日志 → 查看冲突详情
    4. 您可以手动选择保留哪一版本

    12.7 多设备使用示例

    电脑 + 手机协同：

    3. 点击 → 自动下载书籍文件 → 跳到第 3 章 → 高亮和书签都在

    18. 常见问题（FAQ）

    Q1：为什么 AI 功能不能用？

    AI 是 BYOK（自带 key）模式，需要您：

    1. 注册 DeepSeek（或其他兼容服务商）账号
    2. 充值获取 API key
    3. 在设置 → AI 导读中填入

    详见 第 11.1 节。

    Q2：AI 会泄露我的读书内容吗？

    智阅本身不存储 / 中转 / 记录您的对话，但您书中的正文片段 + 高亮 + 提问会发送给您配置的 LLM 服务商。如果您完全不希望内容外发，可：

    • 关闭 AI 功能
    • 或配置本地 LLM（如 Ollama，Base URL http://localhost:11434/v1）

    Q3：跨设备同步需要付费吗？

    智阅本身完全免费开源。WebDAV 服务商可能收费：

    • 坚果云免费版：1 GB 上传 + 3 GB 下载流量 / 月，足够大量同步
    • 自建 Nextcloud：完全免费

    Q4：删书后还能恢复吗？

    ⚠️ 不可恢复
    删除书时会联动删除：
    • DB 中的书 + 9 个子表（高亮 / 笔记 / 进度 / 书签 / AI 会话 / 排版 / 标签 / 自由笔记 / 章节回顾）
    • 本地内容寻址文件（library/{hash}.{ext}）
    • 本地封面文件（covers/{id}.png）
    • WebDAV 上的书籍 binary 和封面（best-effort）
    删除前请确认。同步过的设备会通过 WebDAV 收到删除指令（tombstone），其他设备也会删除。

    Q5：书签跳转位置怎么偏了？

    v1.11.8 引入新的坐标系（plain-text offset），v1.11.7 及之前加的旧书签 charOffset 是 HTML-encoded。v1.11.9 加了 heuristic 自动 rescale 高 ratio 旧书签；低 ratio 旧书签可能有 ≤ 1.73× 小偏差（仍在原章节内）。

    解决方案：删除旧书签，重新添加。

    Q6：手机端顶部图标堆叠看不清？

    v1.11.6 已修复。手机竖屏（width < 600dp）下顶栏改为横向滚动，可左右拖动查看全部按钮。

    Q7：移动端导航条透明看不清？

    v1.11.9 已修复。背景色改为主题自适应（浅色方案给浅底，深色方案给深底），不再用固定黑色 54% 透明。

    Q8：双击没反应 / 全屏切换无响应？

    1. 检查是否在 paged 模式（EPUB）—— 双击切换 chrome 仅在屏幕中部生效
    2. 全屏快捷键：Windows F11 / Esc
    3. 移动端：顶栏 overflow 菜单 → 全屏

    Q9：搜索中文搜不到？

    智阅的全文搜索用 LIKE 子串匹配（非 FTS5 MATCH），原因是 FTS5 默认 unicode61 分词器对 CJK 文本无词边界。

    • 搜「活着」可以命中「人是为了活着本身而活着」
    • 大小写敏感：搜「MongoDB」不会命中「mongodb」（暂未做大小写不敏感，后续优化）

    Q10：导入大 PDF 很慢？

    PDF 导入需要解析页面索引，大文件（> 100 MB）首次打开可能需要 10-30 秒。后续打开走缓存，秒级。

    Q11：坚果云流量用完了？

    免费版限 600 次请求 / 30 分钟。大量导入书籍会触发。等 30 分钟自动恢复。建议分批导入。

    Q12：怎么备份所有数据？

    智阅是本地优先应用，最简单的备份：

    • 方法 A：复制整个数据目录
      • Windows：%APPDATA%\zhiyue\
      • Android：/data/data/com.zhiyue.app/files/（需要 root）
    • 方法 B：配置 WebDAV 同步，让云端作为天然备份
    • 方法 C：定期用 第 14 节的 Markdown 批量导出，把笔记沉淀到 Obsidian

    Q13：TTS 没声音？

    1. 先到 Settings → 朗读 → 「检查 TTS 引擎」看具体状态
    2. Android 用户检查系统 TTS 引擎是否装了 Google TTS（Settings → 系统 → 语言和输入 → 文字转语音输出）
    3. Samsung 用户建议切换到 Google TTS 引擎（com.samsung.SMT 对中文支持差，发音怪异或无声音）
    4. 检查系统音量（媒体音量，不是铃声音量）

    详见第 6.8.6 节。

    Q14：锁屏后 TTS 停了？

    • Android：确认系统设置允许智阅后台运行（设置 → 应用 → 智阅 → 电池 → 不限制后台）。Android 14+ 设备需授予 foreground service 权限（首次朗读时系统会弹窗询问）
    • iOS：应自动续播（UIBackgroundModes: audio 已配置）。如仍停，请到 Gitee Issues 报告设备型号 + iOS 版本
    • 桌面（Windows）：不支持后台播放，仅前台朗读（最小化窗口仍可继续，关闭窗口会停止）

    19. 已知限制

    19.1 v1.11.9-alpha 的已知限制

    1. Bug 1 heuristic 不完美：低 ratio 旧书签（charOffset ≤ plainLen）无法区分新旧格式，小偏差 ≤ 1.73× 仍在原章节内。用户可手动重新添加书签获得精确定位。
    2. PDF 扫描件不支持文本高亮：pdfrx 对扫描件（图像页）只能阅读，不能选文字。文本版 PDF 完整支持。
    3. EPUB 双页渲染：API 层已 wire，渲染层在 v1.6 引入但部分边界情况待打磨。
    4. TTS 后台播放：桌面（Windows）不支持 audio_service，仅前台朗读。iOS 端 UIBackgroundModes 已配置但未真机 build 验证。Android 真机冒烟测试待用户上报。详见第 6.8.5 节。
    5. iOS 端：暂未发布（scaffold 已就绪，待 binary 同步 + CI）。
    6. reader_flow_integration_test 10 分钟 timeout：内部测试基础设施的 pre-existing flake，与用户体验无关。
